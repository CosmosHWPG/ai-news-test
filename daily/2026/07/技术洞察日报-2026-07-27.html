1、加州理工学院提出以知识为中心的自改进范式，智能体保持通用而知识库持久进化

智能体平台、协议与执行系统 Agent 平台与执行系统 知识蒸馏 标准/生态影响

📋 要点：传统的智能体自改进系统以智能体为中心，通过优化提示词、工作流或代码来提升性能，但每次改进都与特定任务绑定，难以复用且维护成本高昂。加州理工学院研究团队提出以知识为中心的自改进范式（KSI），将智能体保持为通用、无状态且可替换的“临时工”，而将持久进化的对象转向一个精心策划的知识库。该协议包含三个阶段：任务级论坛（智能体在任务线程中发帖讨论证据）、跨任务论坛（识别可迁移模式）和知识蒸馏（将讨论精华压缩成可操作的知识包）。实验表明，在ARC-AGI-1抽象推理任务上，配备知识库的简单智能体解决率达86.7%，远超智能体中心方法HyperAgents的70%，且成本仅为后者的三分之一。在Polyglot代码任务上，解决率68%也优于DGM的58%。更重要的是，冻结的知识包可以零样本迁移到新任务，显著提升性能，证明知识包携带的是与模型无关的问题解决结构。

📌 总结：这一范式转变对AI智能体系统的架构设计具有深远影响。它表明，自主推理的瓶颈可能不在于智能体架构的复杂性，而在于其能够访问并随时间精炼的信息质量与结构。外部化知识库使得不同大语言模型和智能体变体可以共享和贡献统一的可重用知识体系，避免了模型特定行为的过拟合。对于构建可协作、可审查的智能体生态系统，该方案提供了即插即用的框架，降低了智能体维护成本，提升了知识可迁移性。未来将知识提炼协议与递归搜索或复杂规划模块结合，有望进一步提升长视野任务性能。对于AI前沿技术预研规划师，这是一个值得关注的新方向。

2、Cursor Agent Swarm使用分层规划-执行架构，廉价模型完成90%编码工作

智能体平台、协议与执行系统 Cursor Agent Swarm 成本下降

📋 要点：2026年7月26日，Cursor在Cursor 3中推出Agent Swarm产品，采用分层智能体架构：planner agent使用GPT-5.5、Opus 4.8等前沿模型递归分解任务，worker agent使用更便宜的Composer 2.5（基于Kimi K2.5）执行任务。在Rust重构SQLite的基准测试中，新系统在4小时内达到73-85%得分，最终全部达到100%测试通过率，而旧系统仅为11-77%。新系统代码量仅为旧系统的15-30%，成本从$10,565降至$1,339（Opus+Composer配置）。Worker模型占Token用量69-90%以上，但成本仅占小部分。

📌 总结：Cursor的Agent Swarm架构证明了分层规划-执行模式在代码生成中的有效性：通过将前沿模型用于高价值决策，廉价模型用于大规模执行，可在保持效果的同时大幅降低成本。该架构对AI编程工具、智能体系统设计有重要参考价值，也为多智能体协作中的冲突解决（如构建自建版本控制系统）提供了实践案例。

智能体平台、协议与执行系统 MSCE 记忆 研发效率提升

📋 要点：2026年7月26日，一篇论文提出MSCE方法，针对多数智能体记忆系统仅保存事件并重新推理导致重复错误的问题，提出将经验组织为声明性事实、诱导性策略和步骤轨迹三层结构，并将重复模式提升为可调用程序（如pip安装失败时自动执行修复规则）。一项策略只有在拥有自身触发条件、边界、正向收益估计和支撑证据时，才成为可调用技能，无需额外微调。该方法为Agent提供了类似人类“技能”的能力，可显著提高执行效率。

1、MonkeyOCRv2提出“重建即视觉记忆”，以像素级文档重建提升视觉编码器，受控实验领先最强对照13.2分

AI模型 MonkeyOCRv2 文档重建 性能提升

📋 要点：2026年7月，研究者发布MonkeyOCRv2，一篇关于文档视觉基础模型的论文。该模型的核心创新是“重建即视觉记忆”，即在训练时同时使用图像到文本生成和像素级文档重建两个目标，使视觉编码器在编码时保留字符笔画、数字形状、标点位置等细粒度信息。在受控实验中，固定后端语言模型为Qwen3-1.7B，仅替换视觉编码器，MonkeyOCRv2-B在8个文档理解基准上取得57.2分，领先最强对照OpenVision-B 13.2分。在CHAOS-Bench（页面内容与语言常识冲突的测试）中，加入重建目标后页面平均召回率从12.1提升至14.7。此外，MonkeyOCRv2在七类文档任务（文字识别、公式识别、文本检测、文档篡改检测、重叠文字分割、文档解析、文档理解）中均带来一致提升。团队同时开源了1.13亿张文档图像的MonkeyDoc v2数据集。

📌 总结：MonkeyOCRv2的工作对文档AI领域具有范式意义：它证明了在文档智能中，视觉编码器不是可替换的前端，而是决定模型能力上限的核心组件。通过重建目标，视觉编码器能够保留更多页面证据，减少语言模型对上下文的依赖。对于技术预研规划师，这意味着在构建文档理解系统时，视觉编码器的选择比语言模型更重要，应优先考虑具有重建预训练目标的设计。同时，开源1.13亿张文档数据集为社区提供了公平比较的起点，推动文档AI从“模型比较”走向“数据+训练协议可复现”的公共研究。

1、Nadella和Hassabis分别发布AI控制框架，一个聚焦企业数据边界，一个聚焦前沿模型准入门槛

AI安全、可信与治理 Nadella/Hassabis AI控制框架 合规/监管影响

📋 要点：2026年7月，微软CEO Satya Nadella和Google DeepMind CEO Demis Hassabis在两天内先后发布了AI控制框架。Nadella的“反向信息悖论”指出企业为AI付费两次：一次在Token，一次在通过提示、纠正和评估泄露到模型中的专有知识。他的解决方案是让企业拥有学习循环（数据、轨迹、评估、适配权重和记忆），并采用模型无关的编排层，使模型商品化，价值流向企业边界。Hassabis的“前沿AI框架”则提议建立类似FINRA的行业标准机构，由行业资助、政府监督，在前沿模型发布前进行网络、生物和欺骗性测试，实验室需在发布前30天提交模型，初期自愿，后期作为美国市场部署的硬性门禁。

📌 总结：这两个框架对技术判断和商业战略有重要影响：Nadella的框架强化了企业数据边界的重要性，建议企业采用模型无关的编排层，这直接支持了多云策略和模型切换能力，对核心网运维Agent等场景有指导意义。Hassabis的框架则可能改变模型发布流程，引入外部测试，影响模型部署节奏。两个框架共同指向一个趋势：AI竞争的核心正从模型能力转移到控制层——谁控制数据边界、部署层和准入规则，谁就掌握价值。对于技术预研规划师，需要关注企业级AI架构中数据主权和模型可替换性的设计；对于商业主管，需要评估这些框架对未来监管和市场竞争的潜在影响。

AI安全、可信与治理 欧盟AI法案 透明度准则 合规/监管影响

📋 要点：2026年7月26日，欧盟《人工智能法案》第50条AI透明度准则将于8月2日正式生效。要求聊天机器人和语音助手必须明确告知用户其为AI系统；AI生成的图片、音频、视频和文本必须附带机器可读标记（如水印、元数据）；用户和机构发布深度伪造内容时须明确说明。8月2日前已面世的生成式AI系统有4个月过渡期（至2026年12月2日）。违规企业最高可被处罚1500万欧元或全面营业额的3%。AI拼写检查和语法纠正工具可豁免。
