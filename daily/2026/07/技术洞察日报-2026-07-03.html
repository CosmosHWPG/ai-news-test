1、腾讯云发布Agent Runtime为智能体提供统一运行底座

智能体平台、协议与执行系统 Agent平台与执行系统 腾讯云Agent Runtime 研发效率提升

📋 要点：腾讯云于2026年7月发布Agent Runtime，这是一套围绕Agent原生执行范式打造的新一代基础设施平台，覆盖接入、运行、治理和智能进化四层。其底层沙箱能力来源于开源项目Cube Sandbox，基于RustVMM与KVM构建硬件级隔离，支持快照、克隆、回滚等生产级能力。在运行层，通过执行引擎、安全沙箱、会话快照和持久化存储提供稳定底座；在治理层，通过工具网关、身份凭证、策略管控和运行观测解决安全合规问题。在Agent RL场景中，Agent Runtime支持每分钟数十万级并发实例创建，毫秒级冷启动和秒级数万并发扩展，已为MiniMax的Forge框架提供百万级吞吐的沙箱环境。在Agentic Agent场景中，支持自动休眠唤醒、故障自愈、checkpoint恢复和虚拟机级强隔离，已在元宝、WorkBuddy等应用中实现100ms冷启动和40万沙箱同时活跃。

2、任务状态表示框架解耦任务状态与屏幕观察，提升移动GUI agent跨应用成功率12个百分点

智能体平台、协议与执行系统 TSR GUI Agent 体验提升

📋 要点：长时程移动GUI agent通常依赖思考-动作-观察循环，但难以区分持久任务状态与瞬时屏幕观察。随着执行历史增长，这种纠缠造成严重上下文负担，导致agent忘记初始需求、幻觉进度或重复与过时界面交互。TSR（Task-State Representation）作为训练自由的轻量级外部包装器，维护三个结构化组件：全局指令摘要、子目标动态进度跟踪器、以及转换感知动作验证器。通过持续更新前后动作视觉比较，TSR有效引导agent推理而无需修改架构。在四个移动GUI基准上验证，TSR在复杂跨应用和内存密集型任务中成功率提升最高12个百分点。

📌 总结：TSR为移动端AI agent的部署提供了一种低成本、高收益的增强方式。对于技术主管和架构师而言，无需重新训练或修改agent模型，只需附加TSR包装器即可显著提升长时程任务的成功率。该方法尤其适合需要跨应用操作或涉及多步记忆的任务场景，如企业流程自动化、个人助理等。其设计思路也可扩展到桌面GUI agent和机器人操作领域。

3、Agentic事务处理：将生成动作视为不可信提案直到通过确定性约束准入的运行时模型

智能体平台、协议与执行系统 智能体执行系统+Agentic事务处理+运行时… 事务模型 安全风险

📋 要点：LLM、求解器和智能体团队越来越多地生成工作流动作、修复和计划，但生成的执行动作可能语法正确却过时、不可行、冲突或破坏触发修复的证据。Stanford/QuadriumAI 提出 Agentic Transaction Processing (ATP) 事务模型，将生成的 action 视为不可信提案，只有通过可执行约束集 C 的确定性准入后运行时才提交执行。ATP 在 Mnemosyne 运行时中实现，包括仅追加事务日志、有效状态投影、依赖安全补偿和主动提交记录，并证明了四个安全属性（权限隔离、序列等价生成准入、证据保持修复、义务约束）和有界响应修复保证。实验显示，在 9 项伪造测试中 ATP 能以低于 6% 的额外开销拒绝违规动作，其局部补偿修复协议（LCRP）的编辑操作数比全局重算少一个数量级。

📌 总结：该论文为 LLM 驱动的 Agent 工作流提供了一种类数据库事务的运行时安全治理方案，使执行状态正确性不依赖提议层的推理能力，极大降低了因生成模型幻觉、恶意或不一致动作导致的系统错误扩散和数据破坏风险。对于正在建设 Agent 编排平台、智能体框架和 AI 工作流引擎的目标读者（预研规划师、架构师、技术主管），ATP 模型可以直接借鉴用于设计 Agent 执行的事务边界、回滚机制和权限分离策略，从而提升多智能体系统的可靠性和可审计性。同时，ATP 对运行时开销的量化评估（<6%、操作数减少10倍）也为工程落地提供了可行性参考。

2、上海交大提出MosaicKV：动态二维KV缓存压缩，长上下文服务吞吐提升7.3倍

AI推理与服务加速 MosaicKV KV缓存压缩 成本下降

📋 要点：长上下文LLM服务的KV缓存与上下文长度线性增长，易导致内存耗尽和吞吐下降。现有压缩技术仅针对序列或单一通道维度，效果有限。上海交通大学提出MosaicKV，一种动态二维KV缓存压缩系统，通过识别每个KV向量的重要元素并在段粒度选择压缩策略，同时利用未充分利用的GPU和CPU资源维护压缩缓存以加速注意力计算。在H800 GPU上，MosaicKV相比未压缩基线实现最高16倍注意力加速、4.8倍解码延迟降低和7.3倍吞吐提升，内存减少3倍，在LongBench和RULER上平均精度损失仅1.76%。

📌 总结：MosaicKV有效缓解了长上下文推理的内存瓶颈，使得部署超长上下文模型（如百万token）更加经济高效。对于AI推理服务团队，可直接集成该技术以降低推理成本、提高并发能力。对于核心网架构师，该方法的细粒度缓存管理思路可启发网络数据面的内存优化。整体，MosaicKV推动了长上下文LLM在实际系统中的落地，降低了TCO。
