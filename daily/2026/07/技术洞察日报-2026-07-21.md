### 1、Jürgen Schmidhuber 联合团队发布自我进化 Agent 系统综述，统一形式化框架覆盖200+工作 {#event-87902}

【智能体平台、协议与执行系统】 【Jürgen Schmidhuber】 【自我改进Agent】 【研发效率提升】

📋 **要点**：2026年7月20日，一篇由 **LSTM** 之父 **Jürgen Schmidhuber** 联合署名的最新综述论文《**Self-Improvements** in **Modern Agentic Systems**: A **Survey**》发布。该综述共97页，提出了一个核心形式化框架：**A_t** = (θ_t, Σ_t)，其中 θ 表示基座模型的神经参数，Σ 表示操作脚手架（包括提示、记忆、工具和控制逻辑）。基于此，论文将所有自我改进工作划分为两条主路径：基座模型改进（θ路径，包括使用内在生成示范、内在评估反馈和外在探索经验）和脚手架改进（Σ路径，包括prompt精炼、记忆管理、工具治理和完整脚手架修改）。
📌 **总结**：该综述为高度碎片化的自我改进 **Agent** 领域（涉及 **Reflexion**、**Voyager**、Gödel **Machine** 等大量工作）提供了统一的形式化分类法和标准术语，有助于研究人员和工程师清晰理解不同技术的定位、优缺点和适用场景。其对模型坍缩风险、reward hacking 等实际问题的讨论也具有工程指导意义。该工作有望成为该领域的标准参考文献。

### 1、腾讯混元开源HiLS-Attention，实现512倍免训外推和15倍推理加速 {#event-87676}

【AI推理与服务加速】 【腾讯混元】 【稀疏注意力】 【性能提升】

📋 **要点**：2026年7月，**腾讯混元**团队开源HiLS-**Attention**（分层地标**稀疏注意力**）。该方法通过一阶泰勒展开构造chunk重要性估分函数（包含相关项和熵偏置），解决了mean/max logits表达力不足的问题；通过分层softmax将代理分数送入前向计算图，实现端到端可训练。在345M至**7B**参数规模上，HiLS在短文本PPL与全注意力几乎重合，8K训练条件下可实现4M上下文（**512倍**）免训外推。512K上下文下prefill加速**13.5倍**，单步decode加速**15.7倍**。在长上下文检索任务上甚至反超全注意力。
📌 **总结**：**HiLS-**Attention为长上下文建模提供了高效的**稀疏注意力**方案，尤其适用于Agent、深度推理等需要超长上下文的场景。对于**AI推理与服务加速**领域，该技术可大幅降低长序列推理的计算和显存开销。对于AI模型领域，HiLS证明了**稀疏注意力**可以同时提升效率和效果，压缩去噪效应甚至带来更纯净的检索表征。该工作已开源，有望被广泛采用。

## 模型训练

### 1、UC Santa Barbara等机构提出长度价值模型实现Token级长度控制 {#event-88598}

【模型训练】 【LenVM】 【长度控制】 【成本下降】

📋 **要点**：2026年7月20日，UC **Santa Barbara**、**CMU**、**LMSYS** Org和UW-Madison联合发表论文“**Length Value Model**: **Scalable Value Pretraining** for **Token-Level Length Modeling**”。**LenVM**将生成长度建模为价值估计问题，为每个token预测剩余生成长度。在LIFEBench精确长度匹配任务上，将**7B**模型的长度得分从30.9提升至64.8。在GSM8K上，以**200 token**预算保持**63%**准确率，而基线仅**6%**。**LenVM**还支持长度预测和可解释性分析。
📌 **总结**：该研究对AI推理成本优化和模型效率提升有直接价值。对于核心网设备供应商，可应用于边缘AI的token预算控制，降低推理延迟和成本。对于技术主管，该技术可集成到推理服务中实现动态长度调整。
来源：[Apple Machine Learning](https://machinelearning.apple.com/research/length-value-model)
原文标题：Length Value Model: Scalable Value Pretraining for Token-Level Length Modeling
