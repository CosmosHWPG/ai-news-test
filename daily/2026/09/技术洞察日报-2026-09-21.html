1、Google Research 提出 RRSI，正则化智能体框架自改进降低 30% token 消耗

智能体平台、协议与执行系统 RRSI 递归自改进 研发效率提升

📋 要点：LLM 智能体的能力很大程度上由其 harness（提示、控制流、工具、记忆与上下文管理）放大，近期方法通过迭代提出并选择组件级编辑来自动化这一过程，形成智能体系统层面的递归自改进（RSI），但此类演化容易记忆训练任务而过拟合，表现为分布内增益大、分布外基准增益缩小甚至消失。Google Research 提出 RRSI，将正则化原则引入 harness 自改进：提议器采用时间退火预算限制单个候选可捆绑的编辑数量，并基于演化历史鼓励未探索轨迹；选择器配备 critic 与 pruner，前者筛除基准特定提案，后者移除过小、过贵或不再有用的改动。

📌 总结：在覆盖编码、智能体工作区与工程设计任务的八个基准上，RRSI 在演化集上最高提升 14.1 分，在五个分布外基准上最高提升 4.7 分，同时产出的 harness 比未正则化演化少用 30% 策略 token。对技术路线而言，这为智能体框架自动优化提供了抑制过拟合、偏好可复用机制的方法论，可降低智能体系统迭代中的算力与 token 成本；代码与项目页已公开，便于工程团队复现并用于自研 Agent 平台的 harness 优化。

智能体平台、协议与执行系统 Jev-Mem 智能体记忆架构 性能提升

1、D-RAC 用 PDF 归一化与多模态 Markdown 转换降低企业文档分块成本 77.8%

AI推理与服务加速 D-RAC RAG 文档摄入 成本下降

📋 要点：企业知识库的检索增强生成系统需要摄入 PDF、Word、演示文稿和扫描件等异构文档格式，其内容常被锁定在复杂视觉布局、多栏页面和密集表格中。基于规则的提取和 OCR 会破坏阅读顺序、压平表格并丢失标题层级，而基于提取文本的全智能体分块则带来高 token 成本和幻觉风险。研究者提出 Document Retrieval-Aware Chunking（D-RAC），将 W-RAC 框架扩展到任意文档格式。D-RAC 首先将任意输入文档归一化为 PDF，利用几乎所有格式都有忠实确定性 PDF 渲染的特性；随后单次多模态 LLM 将渲染页面转换为检索优化 Markdown，将表格改写为自包含散文语句并保留标题层级；之后分块按 W-RAC 方式确定性解析为 ID 可寻址单元，再基于标识符而非文本进行轻量 LLM 分块规划。在 RAG-Multi-Corpus 基准的 236 文档 795 页 PDF 子集上，D-RAC 在 72 分钟内零错误转换和分块整个语料，产生 1748 个检索就绪块。与前沿 LLM 的智能体分块相比，D-RAC 将分块阶段输出 token 减少 95.7%，分块成本降低 77.8%（GPT-4.1 定价）至 85.6%（Gemini 2.5 Pro 定价），分块时间减少 75%，并可线性扩展到 500 页以上文档。

📌 总结：D-RAC 把企业文档 RAG 摄入从规则提取和全智能体分块推进到 PDF 归一化加单次多模态转换，在保持确定性和可观测性的同时大幅降低 token 成本和幻觉风险。对 RAG 技术路线而言，这意味着文档摄入环节可成为独立优化对象，而非简单依赖 OCR 或全智能体分块；对企业知识库产品架构而言，77.8% 至 85.6% 的成本下降和 75% 的时间减少可能显著降低大规模文档入库的运营成本。该工作也提示多模态 LLM 在文档转换中的单次调用即可替代复杂的智能体分块流程。
