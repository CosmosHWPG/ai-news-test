### 1、字节Seed团队连发三篇自进化Agent论文，系统研究闭环递归自我改进 {#event-168458}

【智能体平台、协议与执行系统】 【字节Seed】 【递归自我改进】 【研发效率提升】

📋 **要点**：**字节Seed**团队于2026年9月9日连发三篇论文，围绕闭环**递归自我改进**（**RSI**）展开。Aspire研究模糊目标下的自我进化，发现Agent在模糊目标下多花**2109秒**解读目标，但只有1/12的模型-目标对超过基线。S3Gym研究自我测试、自我评判转化为自我改进，发现自评判的步级一致率与下一步分数变化几乎零相关（r=-0.23），且参数更新可能导致负迁移（如PvZ任务全线低于初始）。HarnessDev研究Agent harness的创建与进化，发现模型能造出可运行的执行系统，但跨未见任务和跨执行模型的鲁棒进化仍是开放难题，部分谱系在held-out任务上直接转负。
📌 **总结**：三篇论文系统性地拆解了自进化Agent的关键问题，揭示了当前RSI方法的局限性：模糊目标下保留增益稀有、自评判与改进之间几乎零相关、harness进化难以跨任务泛化。这些发现为Agent自我改进研究提供了重要的实证基础，表明自我改进既不自动也不均匀，需要更好的评判校准、记忆筛选和轨迹过滤。对于通信设备商和运营商在AI Agent的自主运维和优化场景中具有重要参考价值。

### 2、MemForest框架压缩Agent记忆50%并保持97%以上性能，实现近2倍检索加速 {#event-170090}

【智能体平台、协议与执行系统】 【Agent 平台与执行系统】 【Memory】 【成本下降】

📋 **要点**：Agent记忆系统在长期对话、个性化助手和视频理解中展现出巨大潜力，但持续累积的记忆在推理时带来了巨大的存储和检索成本。2026年9月8日提交的arXiv论文中，研究者提出MemForest，一个通用的记忆压缩框架，可适配各种Agent记忆系统。MemForest通过利用全局语义相似性和局部时间连续性将历史记忆划分为以事件为中心的单元，为每个单元构建最大生成树（**EventTree**），并通过选择高权重边渐进合并冗余记忆节点，降低存储开销。此外，还引入了锚点引导的传播检索机制，从关键节点的时间邻域中检索相关记忆节点，提高检索准确性。在Mem0框架下，MemForest在三个基准上压缩**50%**历史记忆后保留了**97.1%**的原始性能，实现了**1.89倍**检索加速；在多模态M3-Agent框架下，保留**99.7%**性能，实现**2.24倍**检索加速。
📌 **总结**：MemForest为Agent记忆管理提供了一种即插即用的高效压缩方案，在几乎不损失性能的前提下大幅降低存储和检索成本。这对于需要长期运行、处理大量交互历史的Agent系统（如网络运维助手、客服Agent）至关重要，可直接降低推理成本和延迟，提升系统可扩展性。
来源：[研究团队](https://arxiv.org/abs/2609.08273)
原文标题：MemForest: Efficient Agent Memory Management via EventTree Partitioning and Progressive Merging

### 3、MeClear框架通过合作博弈论实现长时域LLM智能体记忆清理 {#event-170132}

【智能体平台、协议与执行系统】 【MeClear】 【记忆清理】 【体验提升】

📋 **要点**：2026年9月8日，arXiv上发布了一篇题为“**MeClear**: **Cooperative Game-Theoretic Attribution** and **Risk-Aware Memory Clearance** for **Long-Horizon LLM Agents**”的论文。长时域LLM智能体依赖外部记忆系统保存用户偏好和任务知识，但传统检索机制优化语义兼容性而非下游效用，常引入过时、误导或冲突证据。**MeClear**框架通过留一法筛选和采样合作Shapley归因来识别具有负下游效用的记忆，并选择性抑制它们。利用归因排名，MeClear执行查询范围的最小清理策略，在不永久改变记忆库的情况下验证清理上下文的任务恢复。在10个长对话记忆池上的实验表明，MeClear实现了**85.9%**的目标召回率和**82.3%**的整体任务恢复率，比留一法基线提高了25.5个百分点。
📌 **总结**：该研究对智能体平台中记忆管理系统的设计具有重要改进价值。**MeClear**框架通过合作博弈论方法解决了传统记忆检索机制忽略下游效用的问题，有效抑制了过时、误导或冲突证据对智能体执行的影响。对于AI前沿技术预研规划师和技术主管而言，该框架可集成到长时域智能体系统中，提升记忆质量和任务恢复能力。特别是对于需要长期交互的智能体应用，如客服助手、个人助理等，**MeClear**能够显著改善用户体验。
来源：[研究团队](https://arxiv.org/abs/2609.09115)
原文标题：MeClear: Cooperative Game-Theoretic Attribution and Risk-Aware Memory Clearance for Long-Horizon LLM Agents

### 5、恢复反事实审计揭示智能体记忆驱逐中不可逆损失占比达67%-100% {#event-169901}

【智能体平台、协议与执行系统】 【记忆驱逐审计】 【恢复反事实】 【性能提升】

📋 **要点**：智能体记忆系统在历史超过固定token预算时必须丢弃存储信息，但现有预算-准确率前沿无法区分驱逐导致的不可逆损失与可恢复的检索失败。为此，研究者引入了**恢复反事实**方法，这是一种每问题配对干预，在读取时上下文中重新注入问题的黄金证据并重新运行相同的读取器。通过结合正确性变化与证据在驱逐后是否保留，将每个可回答的错误分类为可恢复、不可逆或残余。在LongMemEval-S基准上，使用GPT-4o-mini作为主要读取器和判断器，在80k token预算下，**FIFO**、随机和冗余感知驱逐策略的不可逆错误占比为**67%**-**73%**，**LLM-**重要性策略为**60%**；在8k token下，所有四种策略均达到**100%**。
📌 **总结**：该研究首次提供了对智能体记忆驱逐中不可逆损失的精确量化，揭示了现有评估指标无法区分的错误类型。这一发现对智能体记忆系统的设计具有重要指导意义：不同驱逐策略在不可逆损失比例上存在显著差异，且预算越紧，不可逆损失越普遍。对于开发长对话、持续交互智能体的团队，该审计方法可作为记忆系统评估的标准工具，帮助选择更优的驱逐策略以最小化不可逆信息损失。
来源：[研究团队](https://arxiv.org/abs/2609.08279)
原文标题：What Eviction Destroys: A Restore-Counterfactual Audit of Forgetting in Agent Memory

### 6、CreaMem场景感知记忆架构通过生活场景分区减少检索干扰并提升多跳推理 {#event-169912}

【智能体平台、协议与执行系统】 【CreaMem】 【场景感知记忆】 【架构替代】

📋 **要点**：长时记忆是个性化LLM智能体的核心能力，但现有记忆系统存在两大局限：缺乏场景意识，无关生活场景的记忆共享同一检索空间，导致搜索空间膨胀和跨场景干扰；以及从单一视角编码每个记忆，难以检索同一事件的互补视图。**CreaMem**架构通过将记忆分区为多个生活场景记忆来减少检索时的跨场景干扰，并采用情节和特质双视角编码实现跨记忆协同。进一步设计了每记忆平衡采样策略。在两个长时记忆基准上的广泛实验表明，**CreaMem**在所有评估指标上提升了QA准确率，尤其在多跳推理性能上增益显著。
📌 **总结**：**CreaMem**为个性化LLM智能体的长时记忆提供了一种更优的架构方案，其核心创新在于场景感知分区和双视角编码。对于开发个性化AI助手（如虚拟伴侣、个人知识管理工具）的团队，**CreaMem**提供了一种可落地的记忆组织方案，有望显著提升智能体在长对话和持续交互中的表现。
来源：[研究团队](https://arxiv.org/abs/2609.08550)
原文标题：CreaMem: A Scene-Aware Memory Architecture for Personalized Agents

### 7、SE-GoS 框架通过执行轨迹自演化技能图谱，提升智能体技能检索效果 {#event-170081}

【智能体平台、协议与执行系统】 【SE-GoS】 【技能图谱】 【体验提升】

📋 **要点**：该研究针对现代LLM智能体依赖可复用技能，但技能库扩展到数千条目时检索成为瓶颈的问题，提出了自演化**技能图谱**框架。**SE-GoS**是一个训练免费的框架，从执行轨迹中演化现有的GoS图谱，同时保留原始检索流水线。**SE-GoS**执行三种互补更新：拓扑演化（从执行证据中发现和修剪技能关系）、边权重演化（根据历史效果强化检索相关关系）和描述演化（使用执行反馈优化面向检索的技能描述）。在SkillsBench上使用三个LLM的实验中，**SE-**GoS一致地提升了任务奖励，同时相对于加载全部技能减少了输入词元。在一个代表性设置中，一轮演化将奖励从**52.4%**提升至**59.4%**，同时输入词元减少约三分之一，且演化后的图谱可迁移到不相交的保留集上。
📌 **总结**：这项研究对**智能体平台、协议与执行系统**领域具有重要影响。它提供了一种训练免费的**技能图谱**动态优化方法，能够从智能体的实际执行经验中学习，持续提升检索效果并降低上下文成本。这对于构建大规模、可演化的智能体技能库至关重要，使得技能库能够随着使用而不断改进，而无需昂贵的模型重新训练。
来源：[研究团队](https://arxiv.org/abs/2609.08228)
原文标题：SE-GoS: Self-Evolving Graph-of-Skills for Skill Library at Scale

### 8、自演化Agent框架将GPT-4.1在AppWorld上的五次全通过率提升16个百分点 {#event-170118}

【智能体平台、协议与执行系统】 【基础模型 GPT-4.1】 【Memory】 【研发效率提升】

📋 **要点**：LLM驱动的Agent在平均情况下可能准确，但在生产中不可靠。使用**GPT-4.1**的ReAct Agent在AppWorld基准上，五次运行全部成功的概率仅为**53%**，尽管单次通过率平均为**77%**。研究者将这一24个百分点的差距称为“一致性差距”。2026年9月8日提交的arXiv论文中，研究者提出一个自演化Agent框架，通过识别Agent轨迹中不稳定、低一致性的步骤并将其转化为Agent在未来运行中可以借鉴的情景记忆来缩小这一差距。其核心是一致性分析器，精确定位轨迹在多次执行中可能翻转的位置和原因，以及指南生成器，将诊断转化为有针对性的指南。在AppWorld上使用ReAct/**GPT-4.1**，该框架将五次运行全部成功的任务比例提升了16个百分点，类似任务泛化提升了13个百分点。
📌 **总结**：该框架为提升LLM Agent在生产环境中的可靠性提供了一种实用的自演化方法，通过将不稳定步骤转化为可重用的记忆，显著缩小了平均性能与一致性能之间的差距。对于需要高可靠性的Agent应用，如网络运维自动化、金融交易等，具有重要的工程价值。
来源：[研究团队](https://arxiv.org/abs/2609.08832)
原文标题：Closing the Consistency Gap: Self-Evolving Agents That Learn to Stay on Course

### 1、NVIDIA Dynamo实现编码-预填充-解码分离，多模态推理TTFT提升5倍 {#event-170432}

来源：[研究团队](https://arxiv.org/abs/2609.07883)
原文标题：Deadline-Aware Adaptive Prefill Chunking for Efficient Large Language Model Serving

### 2、RouteRelay通过跨层路由元数据复用实现高效动态稀疏注意力 {#event-169855}

【AI推理与服务加速】 【RouteRelay路由复用】 【稀疏注意力】 【成本下降】

📋 **要点**：动态**稀疏注意力**通过将每个查询块路由到少量键块来降低长上下文预填充成本，但路由器每层重建块-块分数矩阵。研究者提出RouteRelay，一种路由器无关方法，跨深度仅复用路由元数据，同时继续使用当前层的查询、键和值计算注意力。锚定层执行完整路由，中间层重新评分前top-k路由和紧凑的哨兵集。仅当哨兵挑战最弱选中块时才重路由查询行。在可复现经验评估中，RouteRelay在低、中、高跨层漂移下分别重路由**25.0%**、**55.4%**和**78.2%**的行，同时保持至少**99.99%**路由召回。
📌 **总结**：该研究为长上下文LLM推理提供了更高效的**稀疏注意力**方案，通过利用层间路由稳定性大幅减少计算开销。对于需要处理超长序列的应用，RouteRelay在保持高路由召回的同时显著降低路由计算成本，具有重要的工程优化价值。
来源：[研究团队](https://arxiv.org/abs/2609.07306)
原文标题：RouteRelay: Event-Triggered Cross-Layer Route Reuse for Efficient Dynamic Sparse Attention

### 3、ComVLA利用语言指导适应VLA令牌预算，在6G连接机器人中降低74%推理计算 {#event-170178}

【AI推理与服务加速】 【ComVLA】 【6G连接机器人】 【性能提升】

📋 **要点**：连接机器人是新兴的6G应用，但VLA模型过大无法在机器人上运行，常见趋势是将推理卸载到云端。然而，无线链路限制了每控制步可传输的传感数据量。**ComVLA**框架利用语言中包含的密集语义信息指示哪些视觉令牌重要，从而将VLA令牌预算适应信道容量。在LIBERO基准上传输32令牌替代512令牌，推理计算降低**74%**，推理延迟降低**22%**，任务成功率仅从**96.9%**下降1.5个百分点至**95.4%**，且在Rayleigh和Rician衰落信道下保持在容量预算内。这些结果表明VLA推理与无线通信的协同设计是**6G连接机器人**的实用方向。
📌 **总结**：**ComVLA**展示了VLA推理与无线通信协同设计是**6G连接机器人**的实用方向，有助于在有限信道容量下实现高效推理。对于5G/6G标准专家和核心网架构师，该工作提供了AI与通信协同设计的参考案例，对6G网络架构设计具有潜在价值。对于AI前沿技术预研规划师，该工作展示了语言指导的令牌剪枝方法。
