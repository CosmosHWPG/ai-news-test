1、字节Seed团队连发三篇自进化Agent论文，系统研究闭环递归自我改进

智能体平台、协议与执行系统 字节Seed 递归自我改进 研发效率提升

📋 要点：字节Seed团队于2026年9月9日连发三篇论文，围绕闭环递归自我改进（RSI）展开。Aspire研究模糊目标下的自我进化，发现Agent在模糊目标下多花2109秒解读目标，但只有1/12的模型-目标对超过基线。S3Gym研究自我测试、自我评判转化为自我改进，发现自评判的步级一致率与下一步分数变化几乎零相关（r=-0.23），且参数更新可能导致负迁移（如PvZ任务全线低于初始）。HarnessDev研究Agent harness的创建与进化，发现模型能造出可运行的执行系统，但跨未见任务和跨执行模型的鲁棒进化仍是开放难题，部分谱系在held-out任务上直接转负。

📌 总结：三篇论文系统性地拆解了自进化Agent的关键问题，揭示了当前RSI方法的局限性：模糊目标下保留增益稀有、自评判与改进之间几乎零相关、harness进化难以跨任务泛化。这些发现为Agent自我改进研究提供了重要的实证基础，表明自我改进既不自动也不均匀，需要更好的评判校准、记忆筛选和轨迹过滤。对于通信设备商和运营商在AI Agent的自主运维和优化场景中具有重要参考价值。

2、MemForest框架压缩Agent记忆50%并保持97%以上性能，实现近2倍检索加速

智能体平台、协议与执行系统 Agent 平台与执行系统 Memory 成本下降

📋 要点：Agent记忆系统在长期对话、个性化助手和视频理解中展现出巨大潜力，但持续累积的记忆在推理时带来了巨大的存储和检索成本。2026年9月8日提交的arXiv论文中，研究者提出MemForest，一个通用的记忆压缩框架，可适配各种Agent记忆系统。MemForest通过利用全局语义相似性和局部时间连续性将历史记忆划分为以事件为中心的单元，为每个单元构建最大生成树（EventTree），并通过选择高权重边渐进合并冗余记忆节点，降低存储开销。此外，还引入了锚点引导的传播检索机制，从关键节点的时间邻域中检索相关记忆节点，提高检索准确性。在Mem0框架下，MemForest在三个基准上压缩50%历史记忆后保留了97.1%的原始性能，实现了1.89倍检索加速；在多模态M3-Agent框架下，保留99.7%性能，实现2.24倍检索加速。

📌 总结：MemForest为Agent记忆管理提供了一种即插即用的高效压缩方案，在几乎不损失性能的前提下大幅降低存储和检索成本。这对于需要长期运行、处理大量交互历史的Agent系统（如网络运维助手、客服Agent）至关重要，可直接降低推理成本和延迟，提升系统可扩展性。

3、MeClear框架通过合作博弈论实现长时域LLM智能体记忆清理

智能体平台、协议与执行系统 MeClear 记忆清理 体验提升

📋 要点：2026年9月8日，arXiv上发布了一篇题为“MeClear: Cooperative Game-Theoretic Attribution and Risk-Aware Memory Clearance for Long-Horizon LLM Agents”的论文。长时域LLM智能体依赖外部记忆系统保存用户偏好和任务知识，但传统检索机制优化语义兼容性而非下游效用，常引入过时、误导或冲突证据。MeClear框架通过留一法筛选和采样合作Shapley归因来识别具有负下游效用的记忆，并选择性抑制它们。利用归因排名，MeClear执行查询范围的最小清理策略，在不永久改变记忆库的情况下验证清理上下文的任务恢复。在10个长对话记忆池上的实验表明，MeClear实现了85.9%的目标召回率和82.3%的整体任务恢复率，比留一法基线提高了25.5个百分点。

📌 总结：该研究对智能体平台中记忆管理系统的设计具有重要改进价值。MeClear框架通过合作博弈论方法解决了传统记忆检索机制忽略下游效用的问题，有效抑制了过时、误导或冲突证据对智能体执行的影响。对于AI前沿技术预研规划师和技术主管而言，该框架可集成到长时域智能体系统中，提升记忆质量和任务恢复能力。特别是对于需要长期交互的智能体应用，如客服助手、个人助理等，MeClear能够显著改善用户体验。

📋 要点：该研究针对现代LLM智能体依赖可复用技能，但技能库扩展到数千条目时检索成为瓶颈的问题，提出了自演化技能图谱框架。SE-GoS是一个训练免费的框架，从执行轨迹中演化现有的GoS图谱，同时保留原始检索流水线。SE-GoS执行三种互补更新：拓扑演化（从执行证据中发现和修剪技能关系）、边权重演化（根据历史效果强化检索相关关系）和描述演化（使用执行反馈优化面向检索的技能描述）。在SkillsBench上使用三个LLM的实验中，SE-GoS一致地提升了任务奖励，同时相对于加载全部技能减少了输入词元。在一个代表性设置中，一轮演化将奖励从52.4%提升至59.4%，同时输入词元减少约三分之一，且演化后的图谱可迁移到不相交的保留集上。

📋 要点：机器学习在3GPP NR 5G分布式单元（DU）内10ms以下频段（链路自适应、每时隙调度、信道估计和接收机）中展示最大增益，但无开放平台允许独立构建软件在此运行。OCUDU dApp平台提供开放运行时和E3接口，签名AI-RAN应用在生产DU内按三类定时合同执行：GPU接收链上常驻（A类）、调度器100us截止时间内（B类）、从不阻塞的观察者（C类）。在GB10 gNB上，所有三类dApp（包括树外神经均衡器）同时在活动小区上运行，无一次回退。平台、SDK和零硬件快速启动作为OCUDU AI-RAN工作组2的预览版发布。

2、FMSGOC框架利用基础模型先验实现0.039 BPP语义通信，保持高保真度

标准、协议与产业联盟 基础模型能力变化 Semantic 性能提升

📋 要点：语义和目标导向通信在6G中日益受研究，但在紧速率预算下泛化到未见数据仍是弱点。FMSGOC使用广泛视觉语言基础模型先验缓解过拟合，通过将比特集中在稀疏目标对齐锚点上并依赖生成基础模型先验重建掩码区域来提高速率效率。视觉语言基础模型选择和传输稀疏语义锚点，预训练扩散模型微调用于掩码完成在接收端重建图像。实验达到0.039 BPP，保持高语义保真度（CIFAR-10余弦相似度0.87-0.90），在未见输入上鲁棒（ImageNet 0.83-0.86），在更低比特率下优于强端到端基线。

📌 总结：FMSGOC为6G语义通信提供了高效框架，展示了基础模型在通信中的潜力。对于5G/6G标准专家和AI前沿技术预研规划师，该方法可推动语义通信从概念走向实用，提升频谱效率。
