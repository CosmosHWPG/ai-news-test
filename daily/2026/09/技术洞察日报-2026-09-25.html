智能体平台、协议与执行系统 ModularRSI Harness自我演化 研发效率提升

📋 要点：IQuest Research联合北京航空航天大学、曼彻斯特大学等发布ModularRSI，研究在基础模型权重冻结条件下，Agent能否通过改造模型外围运行机制Harness获得持续自我改进。方法上把Agent表示为A=(M,H)，将Harness拆为Agent Loop、Observation Management、Tool Use、Context Management、Task Completion Detection五个模块独立演化，从多次rollout轨迹中提取结构化缺陷，经Program Check、Diff Review、Execution Validation三道验证后写回代码，再通过Cross-Module Integration联合演化。实验在Terminal-Bench 2.0上把准确率从47.57提升至52.43，Agent Loop单模块贡献约2.99个百分点，Observation Management使平均交互步数下降约35%；跨领域迁移到SWE-Bench Verified提升2.40个百分点，替换基础模型后GLM-5.2从59.55升至61.80、MiniMax-2.5从41.57升至44.94。

2、北交清华与蚂蚁提出ARGUS，多智能体协作给视频鉴伪补证据链

智能体平台、协议与执行系统 ARGUS视频鉴伪 多智能体取证 安全风险

📋 要点：北京交通大学、清华大学与蚂蚁集团的研究者提出ARGUS，将多智能体协作引入视频鉴伪。系统由纹理、光照、运动、物理四类观察智能体从不同维度独立收集证据，观察阶段不输出最终真假结论，裁判智能体再综合观察报告与抽取的视频帧，对相互印证或冲突的证据进行权衡，输出二元预测和对应取证解释。训练以Qwen2.5-VL-7B为基础，先分别对观察者与裁判做监督微调，再冻结观察者、仅用GRPO优化裁判。团队同时构建FaceVid-Forensics-100K数据集，含10万段视频、覆盖33种合成方法。在域外测试集7636段视频上，ARGUS取得69.87%准确率、81.82%召回率与53.28% F1。

4、Google Cloud API Gateway 公测支持 REST API 直接暴露为 MCP 工具

智能体平台、协议与执行系统 Google Cloud API Gateway MCP 工具暴露 研发效率提升

📋 要点：企业大量能力位于智能体不可见的 REST API 之后，此前要让某个接口可被智能体调用，团队通常需另建并运维一套 MCP 服务器，重复实现网关已具备的路由、认证和配额逻辑。Google Cloud API Gateway 在 Public Preview 中可充当远程 MCP 服务器：在已部署的 OpenAPI 3.0.x/3.1.x 规范上以 x-google-api-management.mcp 注解开启，部署后网关在 /mcp 基础路径提供 MCP 服务，接收标准 MCP JSON-RPC 请求，把每个 tools/call 转码为对应 REST 请求，套用既有策略后再把响应转回 MCP 结果。由于转码请求与普通 REST 调用不可区分，原有 JWT 或 API Key 认证、配额和日志保持不变，MCP 与 REST 共用一条策略路径和一份配额。默认 tools/list 未认证，生产环境需用 JWT 保护；tools/call 始终执行底层 REST 操作要求的认证。当前限制包括 HTTP 204 等空响应体操作不暴露、单网关最多 1000 个工具、MCP 与模型路由不能在同一 API 配置中启用。

📌 总结：该能力把 MCP 工具暴露从“新建服务器”降级为“注解既有 OpenAPI 规范”，直接影响智能体平台与企业 API 治理架构：架构师可复用现有网关的认证、配额与日志链路，避免 MCP 与 REST 双轨策略不一致；技术主管可据此缩短企业 API 智能体化的交付周期；同时 tools/list 默认未认证带来的工具名与输入模式暴露风险，需在安全治理中纳入默认加固项。

📋 要点：DeepSeek 联合清华大学于 9 月 19 日向 arXiv 提交论文，公开其用于大规模 Agent 训练的沙盒基础设施 DSec，作者超过 130 人，梁文锋署名最后一位。DSec 通过统一 Python SDK 提供函数调用、容器、microVM 和完整虚拟机四类后端，把环境拆成基础镜像、工作区、工具包三层独立版本化只读层并用 overlayfs 组合，镜像按需从 3FS 加载。论文披露单个生产单元约 160 个 CPU 节点、3 万核、250TB 内存，日服务约 300 万个沙盒，峰值并发超 38 万，创建速度超每秒 5000 个，单任务最多拉起 3.2 万个沙盒；实测比 tar.gz 打包快 1.76 倍、磁盘写入少 5.5 倍，峰值内存降 40.2%。第 6 节提出由 Agent 建造、为 Agent 服务的环境，用 pack_diff 把会话打成增量快照复用，形成部分 RSI 闭环，同时记录了 Agent 作弊与内核崩溃等失败案例。
