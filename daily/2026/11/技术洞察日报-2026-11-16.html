1、llm-d 用 Wide-EP 与 CPU 卸载把 GLM-5.2 智能体推理成本压到每百万输出 3.55 美元

AI推理与服务加速 llm-d GLM-5.2 智能体推理 成本下降

📋 要点：llm-d 在其 well-lit paths 中新增面向智能体负载的 agentic-serving 配方，以 GLM-5.2-FP8 在 H200 上部署为例，基于 SemiAnalysis Weka 语料中 219 个生产 Claude Code 会话构建负载画像：主智能体请求中位输入 195K token、输出仅 317 token，96% 的主智能体轮次复用至少 90% 输入，输入占全部服务 token 的 98.6%。由于 GLM-5.2 采用 MLA 压缩 KV，张量并行无法切分 KV 缓存，TP=8 会保留八份副本，且跨节点 all-reduce 开销高，llm-d 改用数据并行注意力加专家并行 MoE 的 Wide-EP 路径，并叠加前缀感知路由、CPU 卸载、分离式 prefill/decode 与可选 MTP。实测 64 卡部署在并发 64 到 128 之间输出从 3679 提升到 6281 tok/s，前缀路由捕获 96-97% 可复用前缀，CPU 卸载在并发 128 下把输出从 951 提升到 2776 tok/s，MTP 让 32 卡在 128 并发下维持 30 tok/s/用户。

📌 总结：该案例说明长上下文智能体推理的瓶颈在 prefill 与 KV 复用而非 decode，MLA 模型需要数据并行注意力加专家并行的组合才能释放 KV 预算，这对推理服务架构选型具有直接参考价值。按 H200 每小时 2.71 美元租金测算，64 卡部署的每百万输入 token 成本约 0.05 美元、输出约 3.55 美元，低于 Z.ai 公开的 1.40/4.40 美元与 Claude Opus 4.8 的 5/25 美元，为自建推理集群替代托管 API 提供了可量化的成本依据，但该数字仅覆盖 GPU 租金，不含完整 API 运营成本。

AI模型

1、美团开源 1.6 万亿参数智能体模型 LongCat-2.5 全程基于华为昇腾训练

AI模型 美团 LongCat-2.5 昇腾训练 竞争威胁

📋 要点：美团 LongCat 团队在模型首次亮相一周后开源 1.6 万亿参数 MoE 智能体模型 LongCat-2.5，每 token 激活约 480 亿参数，采用 MIT 许可证支持商用。模型面向长多步任务和编程场景，API 支持百万 token 上下文和最长 12.8 万 token 输出，可理解文本、图像和视频并支持推理开关；图像以原生分辨率转为 token 与文本一起处理。训练侧使用 GitHub 拉取请求的真实软件任务和复现的智能体失败进行强化学习，训练环境屏蔽互联网与 Git 历史。部署侧将专家权重和激活量化到 4-bit，官方自托管方案基于 194 片华为 Atlas A2 昇腾加速器，未提供 Nvidia GPU 指引。在 Terminal Bench v2.1 上取得 88.4 分，接近 Claude Opus 5 的 89.1 分。

📌 总结：LongCat-2.5 的核心意义在于用可开源的万亿参数模型和配套昇腾部署方案，证明中国 AI 芯片可以承担超大模型训练与推理主线，使国产算力方案从备选变为具备商业竞争力的路线；对技术主管和商业主管而言，这意味着推理成本结构、供应链风险和模型选型评估需要纳入国产芯片路径。对 AI 前沿规划师，原生多模态 token 化和 4-bit 量化部署是值得跟踪的工程方向；对核心网和通信设备团队，该模型支持 OpenAI 和 Anthropic 格式并接入 Claude Code、Codex、Hermes 等智能体框架，为本地化智能体部署提供自主可控的模型底座参考。

2、OpenAI 用万级智能体 88 小时攻下纳维-斯托克斯千禧难题

AI模型 OpenAI 千禧难题 研发效率提升

📋 要点：OpenAI 在 9 月 8 日公告中披露，其利用一个 8 月 28 日刚开训、尚未发布的新模型，把约一万个智能体分成可互相通信的小组，配备缓存互联网和代码执行能力，对未解千禧难题发起攻击。9 月 5 日，距首批智能体开工约 88 小时，智能体给出纳维-斯托克斯方程会形成奇点的结论，随后 GPT-6 Astra 用 Lean 在 17 小时内完成逐行核验。整个过程智能体互发 270 万条消息，输出约 1300 亿 token，奥特曼估算成本约一千万美元。OpenAI 表示不领取 100 万美元奖金，并称该模型比 GPT-6 Astra 强得多但未公布名称。

📌 总结：该事件把 AI 数学发现从单模型推理推进到大规模智能体协作加形式化核验的工程范式，证明在可自动验证的数学领域，AI 可以承担长周期、高算力投入的探索任务。对 AI 研发规划而言，它提示智能体集群、缓存互联网、代码执行和 Lean 核验可组合成新的研究流水线；对商业判断而言，一千万美元量级的单题成本和奥特曼关于一年后成本降至百分之一的预期，是评估 AI 科研经济性的关键锚点。

模型训练

1、SII与Xinxu AI将RSI闭环用于前沿预训练，801-30B-A3B基座超越Qwen3-30B-A3B

模型训练 801-30B-A3B 递归自我改进 研发效率提升

📋 要点：SII与Xinxu AI公开了将递归自我改进（RSI）式闭环应用于完整前沿预训练的项目，训练出801-30B-A3B。该项目从零开始，三个月内消耗11.8T tokens，得到总参数30B、每token激活3B的MoE基座。其核心不是迭代模型权重，而是迭代由智能体、研究人员、数据管线和训练设施组成的生产系统，具体分为调试闭环、潜力闭环和经验到指标闭环三类共六条实例，共享上下文基础设施并保存失败原因。数据侧将26万个原始PR转为22万个可执行任务，在九种智能体框架上生成约200万条轨迹，验证后保留110万条、超过100B tokens，智能体数据总量达134B tokens并进入长上下文预训练。

📌 总结：该工作把RSI从后训练扩展到前沿预训练，验证了以可低成本复跑的小闭环替代一次性大训练、以组织记忆承载递归改进的可行性，对预训练配方调整、数据管线设计和训练设施工程化具有直接参考价值。其智能体自动生产可执行可验证轨迹的漏斗方法，为长上下文预训练数据构建提供了可复用路径。但需注意801仅做6.33B tokens轻量SFT、未做RL，对比对象多为完整后训练模型，且数据与配方同时变化，增益不能归因于单一修复，结论仍需多种子复现验证。

AI与通算硬件

1、安纳智芯AX100模拟计算芯片流片单次矩阵方程求解低于100纳秒

AI与通算硬件 安纳智芯AX100 模拟计算芯片 性能提升

📋 要点：据科技日报从模拟计算芯片公司安纳智芯了解，其自主研发的AX100芯片已于2026年10月完成流片，被称为世界首颗全集成一步求解矩阵方程模拟计算芯片。测试显示单次矩阵方程求解时间小于100纳秒，单次计算功耗约80毫瓦。该芯片将矩阵方程直接映射为电路，电路自平衡后一次读出结果，无需数字芯片那样的海量乘加迭代。团队在293万参数Autoencoder和272万参数Transformer上验证，二阶优化方案使训练更新消耗分别减少92%和56%；具身智能运动控制与规划端到端算法提速150%至500%；128×128信道格拉姆矩阵相比数字ASIC与GPU等效吞吐提升20至207倍、等效能效提升27.6至61.3倍。芯片不依赖先进制程。

📌 总结：AX100的意义在于把模拟计算从实验室精度突破推向可流片产线，且不依赖先进制程，为矩阵方程求解密集的AI训练优化、机器人实时控制和通信基带信号处理提供数字芯片之外的新底层硬件路线。对核心网与通信系统而言，信道格拉姆矩阵求解的吞吐与能效提升数据值得关注；对预研规划师而言，模拟计算范式若可扩展，可能改变算力供给结构和供应链风险分布。

📌 总结：该案例说明长上下文智能体推理的瓶颈在 prefill 与 KV 复用而非 decode，MLA 模型需要数据并行注意力加专家并行的组合才能释放 KV 预算，这对推理服务架构选型具有直接参考价值。按 H200 每小时 2.71 美元租金测算，64 卡部署的每百万输入 token 成本约 0.05 美元、输出约 3.55 美元，低于 Z.ai 公开的 1.40/4.40 美元与 Claude Opus 4.8 的 5/25 美元，为自建推理集群替代托管 API 提供了可量化的成本依据，但该数字仅覆盖 GPU 租金，不含完整 API 运营成本。
