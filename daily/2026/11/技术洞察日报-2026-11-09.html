1、吉林大学联合上海AI实验室提出EvoTeam，多智能体团队三层协同进化

智能体平台、协议与执行系统 OhEvoTeam Oh多智能体协作 体验提升

📋 要点：吉林大学联合上海人工智能实验室提出EvoTeam，解决多智能体系统完成100个任务后仍无法从历史经验中成长的问题。EvoTeam将系统成长拆为三个层次：Agent Skills关注个体专业能力积累，Agent Teams关注团队协作架构调整，Interaction Rules关注信息交接规则优化。系统维护全局Agent Pool和可持续更新的Team Library，通过自适应组队、团队范围协作和多级经验进化形成闭环。在GAIA、LoCoBench、LOCA-Bench和BeyondSWE混合任务中平均分59.58，相比Meta-Team的55.55提高4.03分。

📌 总结：EvoTeam将进化从单个Agent延伸到整个团队，使团队成为可复用可进化的经验载体。消融实验显示GAIA上移除交互规则后得分从77.00降至67.00，进一步移除可复用团队后降至61.00，证明团队组织和交互规则均提供实际贡献。跨模型迁移实验中GPT-5.6-Luna和DeepSeek-V4.1-Flash的差距不超过4分，展现出协作经验的跨模型迁移潜力，为多智能体系统的持续进化提供了工程参考。

2、LobeHub用自家Agent团队开发自身产品，30项软件工程任务通过率达70%

智能体平台、协议与执行系统 LobeHub 多Agent协作 研发效率提升

📋 要点：LobeHub团队将自研AI协作平台嵌入日常研发流程，由主管Agent Nasa拆解需求并派发给Coding Agent Dario，Dario完成编码、测试并提交PR，再由Codex代码审查机器人检查问题，Dario根据反馈修改后经人工审阅合并。在FrontierHarness的30道软件工程任务中，优化后的Agent Harness使用Kimi K3完成21道，通过率70%，每道成功任务成本中位数1.68美元，超过Codex和Claude Code。团队还实现了跨项目Agent直接沟通，lobe-ui组件库发布6.0.1版本后上游项目自动收到升级通知。

📌 总结：LobeHub将Agent Loop、Session和工具运行环境拆开管理，使Agent在用户退出对话后仍能后台持续执行任务，并曾用客户端数据迁移任务连续运行2天3小时47分钟、拆出60个任务完成56次独立迁移。这套机制让多Agent协作从演示走向可交付的工程流程，对AI Native组织的研发效率提升和Agent平台架构设计具有直接参考价值，也为人机协同中的验收权归属提供了可操作范式。

AI推理与服务加速

1、Evolving Infra 解耦算力分配与 KV 缓存，智能体推理时延最高降 4.1 倍

AI推理与服务加速 Evolving Infra KV Cache 性能提升

📋 要点：智能体工作负载已成为 LLM 推理需求的主要来源，但现有 prefill-decode 分离式服务系统对算力分配和 KV 缓存管理的运行时自适应能力有限，且依赖的粗粒度信号难以刻画智能体负载的多样性与动态性，导致 prefill 与 decode 节点间负载不均、智能体将复用的 KV 缓存被提前淘汰。Evolving Infra 将算力分配与 KV 缓存管理解耦，使节点可在 prefill 与 decode 之间高效切换；在此基础上，在线规划器根据负载构成匹配 PD 切分比例，智能体感知的分布式 KV 管理器利用智能体上下文管理信号指导缓存淘汰与迁移。在最多 256 块 GB300 GPU 上，针对编码、数学和计算机操作任务，使用 GLM-5.2 与 Kimi K2.6 测试，端到端平均请求时延和 P95 TTFT 相比 NVIDIA 生产框架 Dynamo 最高降低 4.1 倍和 14 倍。

📌 总结：该工作把智能体上下文管理信号引入推理服务的调度与缓存决策，说明面向智能体的推理系统需要从静态 PD 分离走向运行时自适应。对推理服务架构而言，解耦算力分配与 KV 缓存管理可提升异构负载下的资源利用率，降低长上下文智能体任务的尾时延；对产品与商业判断而言，这类优化直接关系到智能体应用的 token 成本与并发承载能力，是推理服务差异化竞争的关键方向。

2、英伟达等提出TacitVLA，用attention mask让动作不等推理文本，延迟最多降低3.4倍

AI推理与服务加速 TacitVLA VLA推理延迟 性能提升

📋 要点：针对推理VLA模型先写推理文本再输出动作导致延迟高的问题，英伟达、纽约大学、UC伯克利、约翰斯·霍普金斯大学和斯坦福大学的研究团队提出TacitVLA，保留训练时写推理对backbone的塑造作用和长程任务中推理文本作为记忆的作用，去掉部署时action expert读取当前步骤推理的环节，唯一改动是attention mask让action expert看不到推理token。在机器人操作和自动驾驶四个benchmark上，TacitVLA成功率与显式推理相当并超过无推理训练，单张H100上LIBERO输出动作从495毫秒降至147毫秒，延迟最多降低3.4倍；在RMBench上平均成功率77.5%，此前最好为56.5%；在RoboMME计数任务上达到82.7%，此前最好为66.8%。

📌 总结：该工作把推理VLA的收益来源拆分为学习写推理和读取推理两种途径，证明动作不需要读取当前步骤的推理文本，仅保留训练时写推理的监督作用即可在部署时跳过推理生成，为机器人操作和自动驾驶的实时控制提供了无需额外模型或调度器的加速方案。对AI推理与服务加速方向而言，这一发现说明推理文本的价值主要在训练阶段而非部署阶段，attention mask级别的改动即可实现3.4倍延迟降低，为VLA模型的服务化部署提供了低成本优化路径；在记忆任务上先算动作再在执行期间写日志的做法，也为长程任务的状态管理提供了工程参考。

3、Cloudflare AI Gateway推出Auto Router公测，基准测试称可靠性提升约10个百分点而成本降至约三分之一

AI推理与服务加速 Cloudflare Auto Router 模型路由 成本下降

📋 要点：Cloudflare通过AI Gateway推出Auto Router公测版，将模型设为cloudflare/auto后由边缘GPU上的Workers AI多头分类模型对请求进行14类任务概率分配，并从复杂性、歧义性、风险程度、上下文依赖度四维打1-5分，结合基准数据按效用=预期质量-自适应成本惩罚选模。Cloudflare公布的基准含97个任务、每模型三次采样和1万次Bootstrap重采样，称可靠性提高约10个百分点、成本约为三分之一，响应头cf-aig-routed-model与cf-aig-routing-reason可审计路由原因。但从业者指出风险评分仅依赖最近几轮、文本上限8KiB，长会话中早期风险标签可能被后续简短指令掩盖。

📌 总结：该产品将模型路由从静态配置推向请求级动态决策，为推理成本优化提供了可审计的工程路径；但风险评分上下文截断、模型池配置漂移和会话缓存复用等问题说明，自动路由在生产环境需配合跨轮次风险标签、会话ID保持和模型池审计，对核心网运维Agent等长会话高风险场景尤其需要注意成本与可靠性权衡。

1、Anthropic公开Claude Code六层审查流程回滚率反降四成

模型评测 Claude Code 代码审查 研发效率提升

📋 要点：Anthropic旗下Claude Code团队公开内部代码审查流程。Claude Code约90%的自身代码由Claude编写，6月到9月合并PR数量翻倍多，Anthropic主代码库每日合并改动从5月约2500次涨至9月超3万次。团队采用六层检查：PR创建前跑测试和构建并由零上下文子智能体审查差异、PR上的AI并行审查与投票核验、安全审查、CI检查、按风险分级的人工审批、合并后主分支复检与功能开关灰度。配合快速发现快速回滚机制，回滚率相对下降超40%。团队还发现AI审查反复标出的问题约59%是首轮审查前就存在的老代码，随后改为满三轮未通过即提醒作者重新思考方案。

📌 总结：该流程证明在AI生成代码体量下，逐行人审不可行但可通过分层自动化检查替代，核心思路是把有没有人读过代码转化为这次改动可能出什么错、由哪道检查阻拦。对核心网设备供应商而言，这一模式对网元软件的大规模AI辅助开发与合规审查具有直接参考价值，尤其零上下文审查器、风险分级审批和事故复盘转为考题的机制可移植到高可靠性通信软件流水线。

1、Evolving Infra 解耦算力分配与 KV 缓存，智能体推理时延最高降 4.1 倍

AI推理与服务加速 Evolving Infra KV Cache 性能提升

📋 要点：智能体工作负载已成为 LLM 推理需求的主要来源，但现有 prefill-decode 分离式服务系统对算力分配和 KV 缓存管理的运行时自适应能力有限，且依赖的粗粒度信号难以刻画智能体负载的多样性与动态性，导致 prefill 与 decode 节点间负载不均、智能体将复用的 KV 缓存被提前淘汰。Evolving Infra 将算力分配与 KV 缓存管理解耦，使节点可在 prefill 与 decode 之间高效切换；在此基础上，在线规划器根据负载构成匹配 PD 切分比例，智能体感知的分布式 KV 管理器利用智能体上下文管理信号指导缓存淘汰与迁移。在最多 256 块 GB300 GPU 上，针对编码、数学和计算机操作任务，使用 GLM-5.2 与 Kimi K2.6 测试，端到端平均请求时延和 P95 TTFT 相比 NVIDIA 生产框架 Dynamo 最高降低 4.1 倍和 14 倍。

📌 总结：该工作把智能体上下文管理信号引入推理服务的调度与缓存决策，说明面向智能体的推理系统需要从静态 PD 分离走向运行时自适应。对推理服务架构而言，解耦算力分配与 KV 缓存管理可提升异构负载下的资源利用率，降低长上下文智能体任务的尾时延；对产品与商业判断而言，这类优化直接关系到智能体应用的 token 成本与并发承载能力，是推理服务差异化竞争的关键方向。
