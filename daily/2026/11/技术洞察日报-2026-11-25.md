### 5、epistemic-guard 用进程外 MCP 收据代理把工具调用伪造与记忆污染纳入运行时校验 {#event-285619}

【智能体平台、协议与执行系统】 【epistemic-guard】 【MCP 收据代理】 【安全风险】

📋 **要点**：针对使用模型上下文协议（**MCP**）的语言模型智能体面临的三类运行时校验缺口——工具调用后叙述虚构未执行或超时的副作用、未验证的模型叙述或网页文本与已执行工具输出一同进入持久记忆、镜像网页满足多源佐证造成回声放大——研究提出 **epistemic-guard** v0.5.2，一个开源 **Python** 库与进程外 stdio **MCP** 收据代理，共 15 个模块、**GPU** 显存占用 0 **MiB**。该方案把 **Ed25519** 签名密钥隔离在进程外，写入 **RFC 6962 Merkle** 日志并做 **AER-1** 收据转换，在 **CPU** 上用经 **SHA-256** 校验的 **OpenVINO INT8** 编码器检查回合后叙述，对 7 个溯源域的 **SQLite** 写入做门控，并折叠逐字与轻度编辑的线缆同步 **RAG** 镜像。在一致性测试中，它拒绝 **100%** 被篡改收据（200 个 **Merkle** 叶），通过 58/58 官方 **AER-1** 摄入向量与 50/50 参考校验导出，验证 **100%** 的 40 次故障注入线缆调用与 100 次并发追加且零密钥泄露，阻断 **100%** 的 100 次未授权记忆写入。在 250 条冻结基准轨迹上达到 **93.2%** 准确率、17.9 毫秒热中位 **CPU** 延迟，比 **12B**-**14B** **GPU** 评审器高 6.4 至 6.8 个百分点且延迟低 4.26 至 **4.5 倍**；在 60 条实时 mcp-proxy 轨迹上以 9.16 毫秒 p50 捕获 **96.15%** 危害。
📌 **总结**：该工作把 **MCP** 智能体的安全边界从执行前线缆检查推进到执行后收据与叙述绑定，用进程外签名、**Merkle** 日志和 **CPU** 端 **INT8** 编码器实现零 **GPU** 显存的低延迟校验，直接回应了工具调用智能体在记忆溯源和动作伪造上的可信缺口。对技术路线而言，它示范了如何在不依赖大参数量 **GPU** 评审器的前提下达到更高准确率与更低延迟，为智能体运行时安全提供了可复用的开源组件；对产品架构而言，收据代理与溯源门控可作为 **MCP** 网关或智能体运行时的标准安全层；对合规与审计而言，RFC 6962 **Merkle** 日志与 **AER-1** 收据转换便于满足可追溯性要求，但实时轨迹上 **38.24%** 的假阳性率提示生产部署仍需调优。
来源：[研究团队](https://arxiv.org/abs/2611.27095)

【智能体平台、协议与执行系统】 【HookEvo】 【生命周期钩子】 【研发效率提升】

📋 **要点**：修复工具使用智能体的失败往往需要协同调整harness对工具回执的解释、上下文组装和动作检查方式。**HookEvo**提出利用现有智能体运行时的**生命周期钩子**来演化任务专用harness，并在**DeepSeek** Harness上实例化。每轮中，独立改进器从执行轨迹诊断失败并提出候选方案，**HookEvo**在匹配任务上评估候选与当前harness，保留更优版本进入下一轮。单个候选可联合编辑可执行插件处理器及其在任务内共享的状态，使工具回执能影响上下文并控制后续动作。使用冻结Qwen3-**4B**执行器，所选harness在报告对比中领先，ALFWorld达**95.41%**、DBBench达**70.56%**、WebShop达**48.17%**、OSBench达**41.67%**。在三种改进器和三种编辑范围（从技能文本到单组件及协同可执行编辑）中，**GPT-6.1** Sol在最大范围下平均增益最大。代码已开源。

📋 **要点**：当前LLM智能体在真实事件预测上仍受两重限制：标准ReAct框架在单一持续增长的上下文中累积推理与证据，而预测任务的结果型奖励信号缓慢且噪声大，难以区分严谨推理与侥幸猜测。该研究提出包含执行框架与后训练的预测训练框架：框架侧提出主动信念状态管理PBM，为智能体配备fold工具将冗长上下文压缩为紧凑信念状态并重置上下文以继续探索；训练侧提出SEIPH五维结果盲评分卡，提供过程质量奖励，并用该奖励以PPO和**GRPO**后训练**35B**模型，得到**DeepForecaster-**PPO与DeepForecaster-**GRPO**。理论上证明理想化fold停止收敛且校准局部奖励降低段级梯度方差；实验上**DeepForecaster-**PPO在ForecastBench和Polymarket-Sim上取得最佳Brier分数，优于基于DeepSeek-**V4-Pro**、**Kimi-K2.**6和GPT-5.5的前沿智能体，DeepForecaster-GRPO在FutureX两项指标上排名第二，消融显示PBM在无训练情况下也能提升基座模型。

### 8、Embodied-Harness以双智能体记忆框架免微调提升机器人操作成功率 {#event-285858}

【智能体平台、协议与执行系统】 【Embodied-Harness】 【双智能体记忆与反思】 【性能提升】

📋 **要点**：基于视觉语言模型的机器人在操作任务中受限于记忆组织不足、失败归因不确定和执行经验复用有限，**Embodied-Harness**提出双智能体框架，在不更新模型参数的前提下改进执行外壳。其中Actor通过机器人控制接口与环境交互，Reflector把执行证据转化为可复用的操作指引；层级记忆架构分别维护短期执行上下文与长期经验知识以支撑执行与反思；基于证据的经验反思把失败诊断建立在可观测交互之上，递归外壳自改进则跨多次尝试持续精炼操作指引。实验在RoboTwin 2.0、RoboSPA和RMBench三个基准上验证了其在环境变化泛化、空间推理、长程规划和依赖记忆的操作上的有效性，成功率分别为**82.4%**、**76.7%**和**94.4%**，真实场景三项操作任务平均成功率达**96.7%**。
📌 **总结**：该工作说明机器人操作能力的提升可以来自执行外壳与记忆结构的自改进，而非依赖模型参数更新，这为VLM智能体在真实环境中的持续适配提供低成本路线；层级记忆与证据驱动失败归因的设计，对智能体运行时、记忆管理和长程规划架构具有直接参考价值，也提示具身智能体产品的迭代节奏可从重训转向经验积累，降低部署后的维护门槛。
来源：[研究团队](https://arxiv.org/abs/2611.27689)
原文标题：Embodied-Harness: Towards Recursive Self-Improvement for Robotic Manipulation

### 1、epistemic-guard 用进程外 MCP 收据代理把工具调用伪造与记忆污染纳入运行时校验 {#event-285619}

### 1、AVERT按请求预算路由token执行层数，混合预算批处理降低TPOT 4.3%至21.2% {#event-285680}

【AI推理与服务加速】 【AVERT请求局部token路由方法】 【层跳过与KV缓存】 【成本下降】

📋 **要点**：层跳过可降低大语言模型推理成本，但请求级预算并未规定如何在生成token间分配层执行。该研究提出AVERT，允许token执行不同层数，同时使每个请求的平均执行深度匹配连续预算。在每个被路由层，路由器读取当前token状态与该请求预算，决定是否执行Transformer块；跳过块的token经过轻量残差适配器，且不在该层写入键值KV条目。单个检查点可在同一批次内服务不同预算的请求。研究在三个LLaMA骨干、六项质量指标与13档预算的234次比较中，AVERT在206次为最佳或并列最佳；在单预算与混合预算批次中，每请求预算平均绝对误差至多1.15个百分点；当按预算分组导致批次填充不足时，混合预算使每输出token解码时间TPOT降低**4.3%**至**21.2%**。
📌 **总结**：该工作把推理成本控制从请求级粗粒度预算细化到token级层执行路由，使同一检查点在同一批次内按不同预算服务请求，缓解了按预算分组造成的批次填充不足问题。对推理服务架构而言，token级跳过且不写KV可同时节省计算与KV缓存，混合预算批处理带来的TPOT下降直接对应服务吞吐与成本改善；对产品判断而言，该方法在三个LLaMA骨干上验证，跨模型架构与长上下文场景的收益仍需验证，且质量指标为通用基准，业务场景相关性待评估。
来源：[研究团队](https://arxiv.org/abs/2611.27738)
原文标题：Average-Depth Variable Execution via Request-Local Token Routing

### 2、THOT 拓扑枢纽最优传输：26万长度零样本召回97.40%，L4 上快于 FlashAttention {#event-285801}

【AI推理与服务加速】 【THOT 拓扑枢纽最优传输】 【长上下文注意力】 【性能提升】

📋 **要点**：长上下文模型使用稀疏或结构化注意力来避免二次成本，但在数十万干扰项中检索少量相关事实的能力会随归一化质量分散而下降。枢纽-辐条最优传输（OT）用局部窗口与 K 个共享枢纽构成的线性规模图替代稠密 L×L 矩阵，并以 **Sinkhorn** 缩放平衡。在分块尾部细化与固定支撑传输拓扑基础上，研究者提出拓扑枢纽最优传输（**THOT**）：其一，通过 simplex sparsemax（O(L log L)）或无排序 token 局部阈值 **ReLU**（O(L)）实现有界支撑容量门控，将多余干扰项质量驱动至零；其二，采用三次扫描 1+2 退火行闭合 **Sinkhorn** 调度抑制二分残差；其三，在批量 split-factor **Triton** 内核（**BF**16 T**ensor Core**、**FP32** 势）中实现精确秩 (**D+2R+1**) **One-Reference-Tile** 伴随；其四，提供分块独占前缀因果变体并验证零未来泄漏。在 **NVIDIA** L4 上，L=128 训练的 sparsemax **THOT** 在 L=262,144 纯任务损失（α=0）下取得**97.40%**零样本固定绑定召回，α=0.05 时达**98.83%**（O(L) 阈值 **ReLU** 在 α=0.05 时匹配，α=0 时为**80.60%**），而 softmax 门控枢纽 OT 降至**3.52%**。双向算子微基准中，内核在 H=8、D=64、L=262K 下前向+**VJP** 耗时**100.1 ms**（比潜在 softmax 快**2.2倍**、编译器临时量小**4.0倍**），L=4096 时**1.34 ms** 对比 cuDNN **FlashAttention** 的**4.37 ms**；多层 LM 运行…
📌 **总结**：该研究用线性规模枢纽图与有界支撑容量门控替代稠密注意力，在**26万**长度下保持**97.40%**零样本召回，并在 **NVIDIA** L4 上以**1.34 ms** 对比 cuDNN **FlashAttention** 的**4.37 ms**（L=4096），同时提供零未来泄漏的因果变体。对技术路线而言，**THOT** 为长上下文模型消除归一化质量分散导致的检索稀释提供了内核级方案，可能影响注意力架构设计；对研发工作而言，**Triton** 内核实现与伴随计算细节可直接复用，降低长上下文推理的工程门槛；对商业判断而言，在 L4 等中端 **GPU** 上实现优于 **FlashAttention** 的性能，意味着长上下文服务可在更低成本硬件上部署，改善推理经济性。
来源：[研究团队](https://arxiv.org/abs/2611.27951)

### 1、MemOnce 记忆架构在 1M 上下文把 Qwen3.5-4B 记忆状态缓存压缩 1313 倍 {#event-286030}

【AI模型】 【MemOnce】 【KV 缓存压缩】 【性能提升】

📋 **要点**：该 arXiv（cs.CL）预印本提出 **MemOnce**，一种为语言模型学习可扩展记忆状态的基础架构，针对长程与持续交互推理的记忆复用问题。标准 **Transformer** 累积逐层、token 级 KV 缓存，随上下文扩展出现线性显存增长与二次复杂度；线性时间架构把历史压缩为定长状态，却难以保留细节。**MemOnce** 由两部分构成：记忆编解码器只缓存末层少量隐藏状态作为紧凑记忆表示，并按需解码回注意力层 KV 缓存；记忆稀疏注意力对每个持续输入自适应检索相关记忆，稀疏索引跨层只计算一次。二者耦合实现即时记忆加载与 KV 解码，在 1M 上下文下适配 **Qwen3.5-4B** 时记忆状态缓存减少 **1313 倍**、prefill 时延降低 **6.9 倍**、吞吐提升 **3.5 倍**、整体记忆性能提升 **5.77%**。
📌 **总结**：若该结论可复现，长上下文推理的成本结构将从随上下文线性膨胀的缓存占用转向可控的紧凑记忆状态，对长程对话、持续学习型智能体与 1M 级上下文服务带来直接的显存与时延收益，并减少为长上下文付出的 **GPU** 与 **HBM** 资源。其稀疏索引跨层只计算一次的取舍，提示注意力稀疏化可在架构层而非算子层获取收益；对模型与推理栈团队，可作为评估记忆增强架构替代纯 KV 缓存路线的依据，但需注意指标来自论文自测，尚待第三方复现。
来源：[研究团队](https://arxiv.org/abs/2611.27973)
原文标题：MemOnce: A Scalable Memory Architecture for Large Language Models
