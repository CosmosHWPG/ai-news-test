1、Google联合多校发布CLASHarness，15款大模型多智能体冲突端到端通过率不足30%

智能体平台、协议与执行系统 CLASHarness 多智能体冲突 安全风险

📋 要点：Google联合Emory、USC、UF、UChicago、UCSB和Columbia发布CLASHarness，首次对15个主流大模型在多智能体冲突下的表现进行评测，覆盖20个真实领域、600个多轮可执行冲突任务、7970张4K视觉证据图片和3284项必测检查点。评测采用三层八阶段自动化生成管线，平均95次API调用合成一个10轮任务包，并以34.9%精确代码检查加65.1%语义三票多数决判分。结果显示，标准20步限制下Claude Opus 5通过率25.2%、GPT-5.6 Sol为24.5%，放宽步数后GPT-6 Astra达28.7%，开源Kimi K3为21.8%；关闭图片输入后所有模型通过率暴跌87%至90%。

📌 总结：该基准把多智能体可靠性从定性讨论推进到可量化评测，指出模型在识破误导、核对真值、修改配置、完成交接的完整链条上任一环节缺失即失败，且收尾动作失败率高达58%至72%。对Agent平台设计而言，需强化证据核验、共享锁释放与下游通知等执行语义；对训练侧而言，CLASHarness可作为可验证奖励信号的数据合成引擎，用于训练不盲从、懂协作的多智能体系统。

2、清华与微软等发布 FDE-Gym，交付智能体最佳仅解决 14/95 任务

智能体平台、协议与执行系统 FDE-Gym 交付智能体评测 约束发现 研发效率提升

📋 要点：2026 年 10 月，清华、上交大、哈佛、斯坦福、微软、Meta 等机构联合发布 FDE-Gym，将 AI 交付现场构建为可执行可复现的智能体环境，含 20 个客户场景、95 项端到端任务、18 个行业，每个任务设计 2 至 7 个变体，超 130 名干系人由脚本模拟。评测采用 L0 至 L3 四级指令控制变量，评分以业务 KPI 相对提升量 U 为基础并扣除沟通成本。13 种模型配置中 Claude Opus 5.5 在 L3 得分 0.56 仅解决 14/95，逐任务选最佳也仅 0.70。

📌 总结：该评测对智能体工程方向有明确指导价值：领先模型从 L0 到 L1 平均分下降 0.28，说明约束发现是最大瓶颈；已获 72% 至 85% 关键事实但业务提升仅 0.60 至 0.70，说明事实到系统的转换才是最后一公里。下一代交付智能体需具备约束追踪、成本感知决策和上线保护三种能力，并学会判断何时不该动手，为 Agent 评测和交付框架设计提供可复现基准。

3、Vercel Labs 开源 agent-desktop 以无障碍树驱动代理操作桌面

智能体平台、协议与执行系统 agent-desktop 无障碍树 成本下降

📋 要点：Vercel Labs 发布 agent-desktop，一个 Apache-2.0 许可的 Rust CLI 与 C 库，为 AI 代理提供 macOS、Windows 和 Linux 上的计算机使用能力。其机制是读取操作系统无障碍树而非截图，为每个可操作元素生成带 ref 的 JSON 快照，代理通过稳定 ref 执行操作，默认无头运行不移动指针。1.0.2 版本于 2026 年 10 月 30 日发布，支持 macOS 13+、Windows 10 1809+ 和 Ubuntu 24.04+，纯 CPU 运行。构建方自报在 Slack、VS Code、Notion 等密集 Electron 应用中减少 78% 至 96% token，Apple Maps 单次查看从 3,811 token 降至 273。

📌 总结：agent-desktop 把桌面操作从像素截图转向无障碍树语义 ref，使不具备视觉能力的编码代理也能驱动原生应用，为代理执行系统提供了一条低成本、模型无关的桌面控制路径。对技术主管而言，可评估将其作为代理工具层替代方案；但自报 token 降幅尚无独立基准，且无无障碍树的 UI 不可见、冷启动 Electron 应用需 10 至 25 秒，落地前需实测验证。

4、DeepSeek Harness 开源 Super-agent 原型，用双层架构与事件驱动接管会话调度

智能体平台、协议与执行系统 DeepSeek Super-agent 事件驱动调度 研发效率提升

📋 要点：2026年10月31日，DeepSeek Harness 团队公布自主 Agent 探索成果 Super-agent 底层架构，并在 GitHub 开源原型 dsh-superagent-prototype。该架构把计算机系统的调度、缓存、存算分离与看门狗思想搬进 Agent，通过双层架构（常驻 Router 层负责人类交互与分派、上下文隔离的 Worker 层并发执行）、事件驱动、异步多信道交互、存算分离与外部 Watchdog 五大模块，在底层接管会话管理与上下文同步。实验中 Super-agent 的 p50 与 p95 任务完成时间分别为 12.4 分钟和 15.7 分钟，优于带 Subagent 工具的单 Session；去掉订阅直通后 Router 决定数增加约 30%，读缓存 token 从 2323 万增至 3177 万；Router 批处理把单个决定分摊的推理时间从 6.4 秒降到 1.6 秒。

📌 总结：该架构把 Agent 从单 Session 被动对话推进到持续在线、并发响应环境事件的系统形态，Router 层批处理与订阅直通机制说明系统层调度可显著摊薄推理开销，为智能体运行时、记忆与权限设计提供工程范式；但实验基于合成负载与简化环境，且团队自述存在双层架构扩展、人机协作、A2A 通信与安全隐私四道未解难题，短期应作为架构参考而非生产结论。

5、DeepSeek开源dsh-superagent-prototype，用双层架构与事件驱动重构跨会话Agent

智能体平台、协议与执行系统 DeepSeek dsh-superagent… 跨会话Agent架构 体验提升

📋 要点：DeepSeek发布《Super-agent设计探索》长文并开源原型项目dsh-superagent-prototype，针对当前主流Agent以单一Session为单位、会话彼此独立、多任务上限受人的注意力限制的问题，提出跨会话保持上下文、同时推进多项任务的连续实体设计。架构上采用Router/Worker双层：Router常驻负责统一路由、对外交互与全局记忆，只调度不执行；Worker上下文隔离、挂完整工具专注单任务。事件驱动侧以群聊、邮件、日程、CI结果等Trigger为核心，设计程序层Fast Path与LLM语义层Slow Path两级过滤、Thread订阅直通、投机执行等机制；上下文管理借鉴编译优化思想，用Inline内联近期信息、Spill外置超长内容并链式召回。

📌 总结：该架构把会话管理与上下文同步从用户手中接管到底层，使Agent从被动应答转向主动推进任务，瓶颈从模型能力转向人的注意力。消融实验显示，Super-agent任务完成时间p50/p95为12.4/15.7分钟，显著优于单Session加Subagent方案（中性提示下p95达29.5分钟），代价是单次实验读缓存token约2323万对605万；去掉直通机制后完成时间几乎不变但Router决定量增约30%、token涨37%。Router批处理压测中Trigger到达速率从每分钟约1条升至约40条时，平均batch从1.0升到2.8，单次请求耗时仅从2.5秒增至3.9秒，单个决定分摊推理时间从6.4秒降到1.6秒。对Agent运行时、多智能体编排与上下文工程的产品架构设计具有直接参考价值。

6、Factory发布Droid 1.0编码Agent harness，程序化工具调用默认开启降低15%成本

智能体平台、协议与执行系统 Factory Droid 1.0 程序化工具调用 成本下降

📋 要点：2026年10月31日，Factory发布Droid 1.0编码Agent harness，最大更新是程序化工具调用默认开启。模型不再逐步调用工具，而是编写JavaScript程序在无文件、网络和系统访问权限的沙箱中运行工具，原始文件、搜索结果和日志保留在程序内，仅打印输出返回模型上下文，独立调用可并发执行。该机制基于CodeAct思路，一次模型请求可驱动数百次工具调用。Factory自报数据显示，在Claude Opus 5.5上Script模式将Droid成本降低15%，基础提示词从20887个token缩减37%至13055个，仅2个工具定义前置加载。

1、Claude Code官方VS Code扩展遭篡改，植入持久化SSH后门影响5000用户

AI安全、可信与治理 Claude Code 供应链攻击 安全风险

📋 要点：2026年10月30日，安全研究人员披露Cursor Marketplace遭入侵，Anthropic官方Claude Code VS Code扩展被篡改，伪装为anthropic.claude-code 2.1.313版本。攻击者在主JavaScript文件开头插入66行恶意加载代码，扩展在VS Code启动或webview面板打开时自动激活，向用户~/.ssh/authorized_keys添加标记为svc-telemetry的SSH公钥，并通过计划任务、crontab、LaunchAgent在Windows、Linux、macOS全平台安装持久化后门。恶意代码收集公网IP、主机名、操作系统版本、Git邮箱及最多40个含KEY、TOKEN、SECRET等关键词的环境变量名，通过未加密HTTP发送至134.209.82.225的8099端口。Cursor已关停扩展市场清除恶意代码，Anthropic通过Open VSX和微软VS Code Marketplace发布2.1.314正式版本。

📌 总结：该事件揭示AI编程工具扩展分发渠道的供应链安全薄弱环节，恶意扩展利用自动更新机制在用户不知情下植入后门，对AI开发工具链的权限管理、扩展签名验证和供应链审计提出紧迫要求。对核心网和通信设备商而言，AI辅助开发工具的供应链安全需纳入整体安全治理框架。

2、研究称约1/17的Agent技能含跳过人工检查指令，现有扫描器漏检

AI安全、可信与治理 Agent技能文件 监督绕过 安全风险

📋 要点：一项大规模研究分析GitHub公开仓库中153万个英文Agent技能文件（SKILL.md），发现约1/17即约8.8万个技能含要求跳过人工检查的指令，其中70.1%在任何场景下无条件生效，而非仅限CI等特定上下文。研究测试了Cisco与NVIDIA两个可调用GPT-5.4的开源扫描器，最多仅检出46%且精确率低于0.4；同一模型在改为询问“监督”而非“恶意”时检出率达61%、精确率0.71。

📌 总结：Agent技能文件作为按需加载的指令载体，一行“无需确认即可推送”即可移除所有加载该技能的Agent的人工检查点。该结果说明仅按恶意软件思路扫描技能不足以覆盖监督绕过风险，需将技能审查目标从恶意检测转向监督完整性，并对“不要询问”类指令强制限定上下文，对Agent权限沙箱与审计机制设计有直接指导意义。

3、Cisco Talos 披露 VOLTA 窃密木马，用 LLM 给受害者资产按变现价值排序

AI安全、可信与治理 Cisco Talos VOLTA 多模型降级链 安全风险

📋 要点：2026年10月31日，Cisco Talos 发布对自删除式 Windows 窃密木马 VOLTA-AUTODOXER 的分析。该木马在窃取浏览器密码、Cookie、支付卡、加密钱包助记词、会话令牌和云凭据后，构建包含地理位置、雇主、推断出生年份等信息的结构化证据包，并通过 OpenRouter 以系统提示要求模型充当取证情报分析师，输出按变现价值分级的资产清单和安全态势评估。默认模型为 anthropic/claude-opus-4.6，温度设为 0.2，若检测到拒答则依次降级至 moonshotai/kimi-k2 和 google/gemini-2.5-flash。木马自删除且不依赖攻击者自有基础设施。

📌 总结：该案例显示 LLM 在恶意软件中的角色从辅助能力转向替代人工分析环节，且攻击者已把模型拒答作为工程设计前提并预置降级链。对安全防御而言，需关注模型护栏在多模型路由场景下的可绕过性，以及端侧凭据、会话令牌被用于自动化情报富化所带来的隐私与权限风险。

📋 要点：2026年10月，Snorkel AI 在 Databricks 博客披露其 CI/CD 实践：原先每个 PR 环境需从 Amazon Aurora PostgreSQL 全量恢复数据库，耗时约 20 分钟，难以支撑全天候 PR 与合并队列。团队改用 Databricks serverless Postgres 数据库 Lakebase，利用其存储计算分离与 copy-on-write 分支能力，在 PR 打开时通过 API 从持续同步的主分支创建独立可写分支，分支创建为元数据操作、不复制数据，60 秒内就绪；主分支经 AWS DMS 持续复制保持与生产约 2 分钟差距，分支按 TTL 自动过期，计算按分支弹性伸缩并可缩容至零。
