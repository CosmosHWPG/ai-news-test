### 1、EMAS证据引导演化多智能体系统，在MBPP上准确率提升至89.12%且token成本降低62.2% {#event-122543}

【智能体平台、协议与执行系统】 【EMAS】 【多智能体演化】 【成本下降】

📋 **要点**：**EMAS**（演化多智能体系统）利用经验来修订MAS拓扑和提示，无需更新LLM参数，旨在提高准确率或降低成本。**EMAS**将轨迹转换为结构化诊断，指定修订操作和目标。仅当相同诊断在样本中重复出现时，才生成候选修订，并仅在当前MAS的配对验证满足接受标准时应用。在四个基准和两个LLM上，EMAS在任务加权整体准确率上均达到最高，并在八个模型-基准设置中的六个中最佳或持平。在两个演化周期内，EMAS在Kimi-**K2-**6和Qwen3.6-**27B**上分别实现**6.30%**和**20.10%**的相对准确率提升。在MBPP上，EMAS将准确率从**55.09%**提升至**89.12%**，同时将每任务token使用量减少**62.2%**。
📌 **总结**：**EMAS**展示了如何将新样本的经验转化为MAS拓扑和提示的可复用更新，为自动化智能体设计提供了新范式。其证据引导的修订机制确保了更新的可靠性，同时显著降低token成本，对于大规模智能体部署具有重要经济价值。该研究对智能体平台和协议设计有直接影响，可提升智能体的自适应能力和成本效益。
来源：[研究团队](https://arxiv.org/abs/2608.07196)
原文标题：EMAS: Stabilizing Multi-Agent System Evolution through Evidence-Guided Revision

### 3、SkillAligner在执行时适应检索技能，提升语言智能体任务性能 {#event-122408}

【智能体平台、协议与执行系统】 【SkillAligner】 【技能适应】 【成本下降】

📋 **要点**：通用技能承诺为语言智能体提供可重用程序知识，但语义相关性不保证执行效用：检索技能可能编码与当前任务、执行环境或其他技能冲突的假设。研究将问题形式化为技能-执行不匹配。提出**SkillAligner**，无训练执行时**技能适应**框架，将检索技能视为可适应草稿而非固定指令。执行前，**SkillAligner**进行一次联合适应，将有用技能片段特化到任务需求，对齐其程序假设与可用执行接口，并通过解决依赖、冲突和冗余组合结果指导。适应内容整合为紧凑执行指南，并在后续轨迹中重用。在多样智能体基准和模型骨干上的广泛实验显示，SkillAligner显著提升任务性能，减少技能引起的实例级回归，并降低总推理成本。
📌 **总结**：该方法为语言智能体技能使用提供了新框架，可提升任务执行效率和准确性。对于智能体平台，可能影响技能管理和执行系统设计。虽然与通信关联弱，但方法论可迁移至网络运维智能体。
来源：[研究团队](https://arxiv.org/abs/2608.06880)
原文标题：SkillAligner: Treating Retrieved Skills as Adaptable Drafts at Execution Time

### 4、TEPA机制撤销过期记忆，提升语言智能体在动态环境中的鲁棒性 {#event-122570}

【智能体平台、协议与执行系统】 【TEPA】 【记忆撤销】 【性能提升】

📋 **要点**：**TEPA**提出可撤销的证据记忆机制，将有效性作为记忆的显式状态。它表示观察为键控先例，当新证据与同一键下的先例矛盾时，撤销活动先例，允许检索从当前证据中提取，同时保留撤销历史以供审计。在受控漂移、真实文件执行和偏好更新流中，撤销防止了旧记忆在反转后保留在检索集中。在50个种子的受控漂移中，追加和最后写入记忆在完全反转时低于无记忆（0.210 vs 0.309），而**TEPA**达到0.950。
📌 **总结**：**TEPA**为语言智能体提供了记忆生命周期管理机制，提升其在动态环境中的可靠性，对智能体架构有参考价值。
来源：[研究团队](https://arxiv.org/abs/2608.07429)
原文标题：TEPA: Revoking Stale Memories for Conflict-Robust Language Agents

### 5、TRACE框架通过验证器引导压缩，提升长程智能体上下文可靠性 {#event-122369}

【智能体平台、协议与执行系统】 【TRACE】 【上下文压缩】 【研发效率提升】

📋 **要点**：循环**上下文压缩**控制长程智能体的上下文增长，但其行为影响尚不明确。初步实证研究表明，压缩会削弱近期交互的影响，增加阻塞动作、重复探索和跨运行不稳定性。**TRACE**框架通过验证器引导，评估单个压缩事件，使用来自相同环境状态的配对闭环延续，并利用摘要偏好优化自然语言压缩提示，同时保持所有模型冻结。在AppWorld上的初步结果显示，**TRACE**在任务性能、多运行可靠性和上下文执行效率上优于现有压缩基线。这些发现为可靠的智能体**上下文压缩**提供了边界局部评估的早期证据。
📌 **总结**：**TRACE**通过验证器引导的压缩评估，解决了长程智能体中**上下文压缩**导致的行为不稳定问题，提升了任务性能和多轮可靠性。其方法无需重新训练模型，有实用价值。对于AI前沿技术预研规划师，**TRACE**可启发在智能体设计中优化上下文管理的方法。
来源：[研究团队](https://arxiv.org/abs/2608.06503)
原文标题：Toward Reliable Context Compression for Long-Horizon Agents: An Empirical Study of Execution Instability

### 6、记忆压缩中立场保留：显式标签提升15点 {#event-122606}

【智能体平台、协议与执行系统】 【记忆压缩】 【立场保留】 【研发效率提升】

📋 **要点**：2026年8月6日，研究探讨智能体**记忆压缩**中**立场保留**。通过匹配笔记，仅改变立场位置，压缩后盲读评分。在60个声明中，将立场写为标签字段而非括号旁注，保留率提升约15点（37 vs 2，30 vs 8，p=0.00005），预注册复制在Haiku上+15.6点。消融显示标签在两个模型上均有帮助，长度无帮助，但完整句子在一个模型上有效。结论：使立场显式而非更长，最佳方式依赖模型。
📌 **总结**：该研究为智能体记忆设计提供了实证，显式立场标签可提升保留。对智能体平台，该研究可优化记忆系统。对预研团队，该研究为**记忆压缩**提供了设计原则。
来源：[研究团队](https://arxiv.org/abs/2608.06953)
原文标题：Explicit, Not Longer: What Makes Epistemic Stance Survive Memory Compression

## 模型训练

### 1、FACTOR分离动作与token信用分配，提升多轮智能体强化学习 {#event-122535}

【模型训练】 【FACTOR】 【信用分配】 【性能提升】

📋 **要点**：多轮智能体强化学习中的**信用分配**涉及轨迹级动作信用和动作内token信用。**FACTOR**分离这些决策，使用检查点校准TD残差分配动作信用，可望远镜到轨迹优势；使用反馈条件教师-学生似然差距分配每个信用到实现的动作token。每动作归一化保留动作平均系数，防止token级符号翻转。结合动作均值减少，移除动作标量替代权重对token长度的隐式依赖。在行为策略和裁剪前，每个动作的内部动作均值替代等于其TD信用。**FACTOR**在ALFWorld、WebShop和ScienceWorld上一致优于竞争基线，每个环境-种子比较均有利，最大增益出现在最长程环境。相同超参数无需重调即可迁移至更大骨干和不同模型家族。消融显示TD动作信用是主要驱动因素。
📌 **总结**：**FACTOR**提供了更精细的**信用分配**方法，提升多轮智能体训练效果。对于**模型训练**，该工作可应用于强化学习智能体，提高样本效率。
来源：[研究团队](https://arxiv.org/abs/2608.07118)
原文标题：How Much, Then Where: Credit-Conserving Action-to-Token Allocation for Multi-Turn Agent Reinforcement Learning

### 1、StepJack基准揭示多步间接提示注入攻击显著提升计算机使用智能体风险 {#event-122464}

【AI安全、可信与治理】 【StepJack】 【提示注入】 【安全风险】

📋 **要点**：针对计算机使用智能体面临的间接**提示注入**威胁，**StepJack**提出多步间接**提示注入**攻击，将对抗目标分解为多个看似无害的子步骤，并分布在智能体导航路径上的页面链中。通过自动分解管道，在保证子步骤执行能实现原始目标的同时优化每个子步骤的无害性，构建了包含480个测试样本的**StepJack**基准。评估六个先进计算机使用智能体发现，在固定分解深度下，多步攻击使三个智能体的攻击成功率提升，最高达31.2个百分点，例如GPT-5.4-mini从单步**41.7%**升至三步**72.9%**。平均而言，五个能可靠遵循参考链的智能体攻击成功率从**31.3%**升至**36.9%**。
📌 **总结**：**StepJack**揭示了计算机使用智能体面临的多步间接**提示注入**攻击威胁，表明现有安全评测可能低估了风险。该基准和攻击管道为安全社区提供了评估和防御此类攻击的工具，有助于推动更 robust 的智能体安全机制研究，对依赖计算机使用智能体的自动化任务具有重要安全意义。
来源：[研究团队](https://arxiv.org/abs/2608.06477)
原文标题：StepJack: Benchmarking Computer-Use Agent Safety Against Multi-Step Indirect Prompt Injection
