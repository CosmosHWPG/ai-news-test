### 2、哈工大深圳与新加坡国立提出QuantWM，视频世界模型2-bit KV Cache压缩最高6.20倍 {#event-209724}

【AI推理与服务加速】 【QuantWM】 【KV Cache量化】 【性能提升】

📋 **要点**：视频世界模型基于自回归生成连续画面，KV Cache保存历史画面以维持场景一致性，但显存成本高昂，例如LingBot-**World-**v2生成约**5秒**93帧视频KV Cache就需超过21 GiB显存。现有2-bit **KV Cache量化**方法在视频世界模型上即使VBench评测分数接近BF16，生成画面仍出现明显闪烁、模糊和细节失真。哈尔滨工业大学（深圳）iLearn-Lab与新加坡国立大学LV-Lab研究发现，仅量化Key比仅量化Value带来更明显视觉退化，原因是量化Key改变了注意力分数相对排序，使模型关注另一帧或另一空间位置。**QuantWM**提出量化敏感性感知聚类QSAC，利用Query敏感性加权距离筛选候选中心并结合残差动态范围估计INT2量化扰动；主子空间注意力补偿PSAC以低秩形式保存Key量化误差在主方向上的分量并补偿。在Matrix-**Game-2**、LingBot-**World-**v2、**HY-World 1.**5等五种模型上，**QuantWM**的PSNR、**SSIM**、LPIPS均优于QVG与KIVI，最高分历史token选择变化比例从**53.88%**降至**10.19%**，实际KV Cache压缩最高达**6.20倍**。
📌 **总结**：**QuantWM**对推理服务与显存优化路线的影响在于，它指出视频世界模型低比特KV Cache压缩不能只看基准指标，还需结合实际视频表现和模型对历史信息的利用方式评估。免训练特性使其可直接接入现有生成流程，专属Triton内核在考虑聚类中心、量化参数及补偿信息等额外开销后仍实现**6.20倍**压缩，为长视频生成和边缘部署降低显存门槛。对核心网等需要长序列状态管理的系统，这种从注意力保护角度修正量化误差的思路可借鉴到KV Cache管理和状态压缩场景，提示量化误差对检索排序的影响可能比误差绝对值更关键。
来源：[机器之心](https://www.jiqizhixin.com/articles/2026-10-07-3?source=rss)

### 3、Virginia Tech 提出 Hybrid Latent Attention，循环模型吞吐最高提升 7.4 倍 {#event-211362}

【AI推理与服务加速】 【Hybrid Latent Attention】 【KV Cache压缩】 【性能提升】

📋 **要点**：2026年10月，**Virginia Tech** 发表论文提出 **Hybrid Latent Attention**，针对循环语言模型每个 token 多次经过同一层导致 KV 缓存膨胀、单 **GPU** 可容纳请求数下降的问题，将最后 128 个 token 保持精确、把更早的 token 压缩为紧凑向量供注意力直接读取，无需重建缓存。在 **Ouro** 模型上，16K token 场景吞吐最高提升 **7.4 倍**，单 **GPU** 可容纳请求量提升 4.0 至 **8.8 倍**，数学、知识和推理精度保持在原始水平的 **97%** 以上，且可通过只训练新增部分对已有循环检查点做改造。

📋 **要点**：2026年10月，**Virginia Tech** 发表论文提出 **Hybrid Latent Attention**，针对循环语言模型每个 token 多次经过同一层导致 KV 缓存膨胀、单 **GPU** 可容纳请求数下降的问题，将最后 128 个 token 保持精确、把更早的 token 压缩为紧凑向量供注意力直接读取，无需重建缓存。在 **Ouro** 模型上，16K token 场景吞吐最高提升 **7.4 倍**，单 **GPU** 可容纳请求量提升 4.0 至 **8.8 倍**，数学、知识和推理精度保持在原始水平的 **97%** 以上，且可通过只训练新增部分对已有循环检查点做改造。
