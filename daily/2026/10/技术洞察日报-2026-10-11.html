1、CAVEWOMAN 评测揭示输入压缩反而推高推理成本

AI推理与服务加速 CAVEWOMAN 双通道压缩评测 成本下降

📋 要点：2026年10月，CAVEWOMAN 论文提出双通道评测协议，针对“简短表达省 token”的流行做法，分别衡量用户提示压缩与模型输出压缩对实际成本的影响。研究在八个模型、五个数据集、五个压缩级别上评测，同一批样本同时测量两个通道。结果显示输出压缩在多数 API 模型上降低实际成本 1.4-2.4 倍，最佳情况达 3 倍，四个开放权重模型在公开定价下同样受益；输入压缩则相反，五基准均值净成本上升约 1.15 倍，最差数据集达 1.8 倍，强压缩下达 2.7 倍，原因是模型以更长回复补偿，同时准确率下降。非推理模型约一半生成结果正确，但其表层文本已不再蕴含模型自身无约束基线生成。

📌 总结：该研究对推理成本优化与提示工程策略有直接指导意义：输出侧压缩可作为降本手段，输入侧压缩则可能适得其反。对 serving 系统与 API 定价设计而言，需区分压缩通道并监控模型补偿行为。对预研规划而言，该协议提供了可复用的双通道评测方法，提示在成本优化中不能笼统假设“短即省”。

1、面壁智能联合多校提出 SimpleMemVLA，用原生视觉上下文做机器人记忆

AI模型 SimpleMemVLA 原生视觉上下文记忆 性能提升

📋 要点：2026年10月，面壁智能联合华中科技大学、中国人民大学、清华大学、北京大学、北京智源人工智能研究院和北京中关村学院提出 SimpleMemVLA，论文地址为 arxiv 2609.05533，代码和模型已在 GitHub 与 Hugging Face 开源。该方法不增加专用记忆模块，直接把带时间戳的视觉历史按视频格式组织为上下文，当前腕部画面单独输入，模型生成当前子任务后，其上下文隐藏状态与词元嵌入、机器人本体状态一起传给动作头生成动作。按论文设置，60 秒历史仅占约 5.6k token，主干模型支持 262k token 上下文。在 RoboMemArena 的 26 项任务中，使用 126 秒历史窗口时全阶段任务成功率达 63.6%，比此前最强模型提高 17.4 个百分点。

📌 总结：该工作对机器人记忆机制提出反直觉结论：在长上下文主干模型支持下，保留仍可读的原生视觉历史比提前决定保留什么的写入时承诺更有效，消融实验显示关键画面和时间顺序不可缺少。流式推理通过复用历史前缀的键值缓存，把 60 秒历史决策延迟从 1.02 秒降至 0.68 秒，低于实测任务 0.96 秒实时预算，说明分钟级记忆可跟上实时控制，为 VLA 模型的长程任务能力提供了可复用的工程路径。

3、字节 Seed 联合普林斯顿等揭示 DeepSeek-V4 分块 KV 缓存压缩引发相位敏感性

AI模型 DeepSeek-V4 KV 缓存压缩 性能提升

📋 要点：2026 年 10 月，字节跳动 Seed 团队联合普林斯顿大学、斯坦福大学及加州大学伯克利分校发表论文《Periodic Weak Spots: Phase Sensitivity from Chunked KV-Cache Compression》，系统测试 DeepSeek-V4 和 V4.1。研究发现，DeepSeek-V4 的 CSA 压缩稀疏注意力采用长度 8、步长 4 的重叠滑动窗口，使 Token 绝对位置对步长取模产生隐式相位，导致同一信息因位置不同而检索准确率差异显著。在 128K 长上下文大海捞针实验中，V4-Flash 基座模型最差位置组检索准确率仅 29.69%，最好位置组达 69.92%，相差 40.23 个百分点。V4.1-Flash 将步长减半后落差收窄至 6.1 个百分点，但周期性未完全消除。

📌 总结：该研究揭示固定步长分块 KV 缓存压缩在数学上打破平移对称性，使信息检索能力随 Token 位置周期性波动，而传统长文本榜单的平均分掩盖了最差位置的断崖式下跌。对模型架构而言，这意味着压缩比、步长与检索可靠性之间存在权衡，步长减半可缓解但无法根除相位敏感性。对推理服务与评测体系而言，需要引入最差位置表现和相位分组测试，避免平均分伪造平稳高分。对核心网等长上下文分析场景，该缺陷提示在依赖压缩注意力处理长日志或信令数据时需评估位置敏感性风险。

📋 要点：2026年10月，面壁智能联合华中科技大学、中国人民大学、清华大学、北京大学、北京智源人工智能研究院和北京中关村学院提出 SimpleMemVLA，论文地址为 arxiv 2609.05533，代码和模型已在 GitHub 与 Hugging Face 开源。该方法不增加专用记忆模块，直接把带时间戳的视觉历史按视频格式组织为上下文，当前腕部画面单独输入，模型生成当前子任务后，其上下文隐藏状态与词元嵌入、机器人本体状态一起传给动作头生成动作。按论文设置，60 秒历史仅占约 5.6k token，主干模型支持 262k token 上下文。在 RoboMemArena 的 26 项任务中，使用 126 秒历史窗口时全阶段任务成功率达 63.6%，比此前最强模型提高 17.4 个百分点。

📌 总结：该工作对机器人记忆机制提出反直觉结论：在长上下文主干模型支持下，保留仍可读的原生视觉历史比提前决定保留什么的写入时承诺更有效，消融实验显示关键画面和时间顺序不可缺少。流式推理通过复用历史前缀的键值缓存，把 60 秒历史决策延迟从 1.02 秒降至 0.68 秒，低于实测任务 0.96 秒实时预算，说明分钟级记忆可跟上实时控制，为 VLA 模型的长程任务能力提供了可复用的工程路径。
