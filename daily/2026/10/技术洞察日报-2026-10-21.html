2、Databricks 发布 MemCurrent 持久记忆架构，Agent 通过率提升至三倍

智能体平台、协议与执行系统 Databricks MemCurrent Agent 持久记忆 性能提升

📋 要点：Databricks 发布 MemCurrent 生产级 Agent 持久记忆架构，解决 Agent 在长尾任务上质量与效率难以兼顾的问题。该架构包含两类记忆：情景记忆存储原始会话轨迹，派生记忆以文件形式存储从轨迹中提炼的经验，顶部由自动生成的 memory.md 索引描述文件结构。访问模式有三种：插件在会话固定点自动读写，工具让 Agent 按需调用 add_memory、update_memory、delete_memory 和 search_memory、fetch_memory，离线 dreaming 管线在后台整合记忆、拆分大文件、合并重复项并解决冲突。在内部基于真实 Genie 会话构建的基准上，MemCurrent 将 Agent 通过率从无记忆的 22.3% 提升至 68.4%，同时速度提升 1.35 倍，成本降低 1.44 倍。

📌 总结：MemCurrent 证明持久记忆可以同时改善 Agent 的质量与效率，打破此前二者取舍的困境。对技术路线而言，情景记忆与派生记忆的分层设计、在线工具与离线 dreaming 的职责分工，为 Agent 记忆系统提供了可参考的架构范式。对产品架构而言，记忆作为不绑定单一 Agent 或 LLM 的知识库，可随用户迁移并可能为组织内共享知识提供种子。对商业判断而言，Agent Bricks Memory 和 Genie 已内置该能力，降低了企业构建生产级 Agent 的记忆门槛。
